    使用开发控制代码（Devel Codes）

    中文译文 · 由本地英文文档翻译，已统一术语并进行重点抽查。 英文原文对照 · 翻译说明

    本文件旨在描述开发人员使用devel代码以加快实验参数实现的过程。

    什么是开发代码

    开发版本代码是开发者在功能尚未准备好公开发布时控制特性的重要工具。开发版本代码从以下位置读取 devel_code 块的 .param 文件。

    开发代码比关键字更容易使用，然而它们没有关键字所具备的严格类型/值检查或单位转换功能。此外，开发代码不可搜索，也不提供任何帮助信息。要使用开发代码，必须明确知道如何调用它们、应取哪些值以及它们的作用。

    开发代码块是一个任意字符串，可用于向函数提供参数；然而，开发代码块还包含若干有用的标准化结构元素，使其比仅仅作为一个需要自行解析的字符串更为实用。

    使用开发版本的代码

    开发代码子模块

    开发代码被划分为若干子模块，这些子模块通常以其支持的模块或功能命名。

    例子包括：

    • MD — 与分子动力学选项相关
    • FIRE — 与 FIRE 几何结构优化方法相关的内容
    • ELECTRONIC — 与电子最小化相关

    然而它们可以是开发者希望的任何内容。

    说明

    虽然从原则上讲，模块名称是通用且任意的，但将它们与所使用的模块或其功能相关联，有助于记住如何调用它们。

    块的另一个用途是为特定算法分配一个独立的块，或者以类似风格的形式组织一个结构化的块。 .cell 样式块（即 %block ... %endblock）在功能完成后将准备集成到主参数中。

    一个子块在中的结构 .param 文件（此处） XYZ) 如下所示：

    %block devel_code
XYZ: param=3 :ENDXYZ
%endblock devel_code

    提取开发代码

    开发代码块在读取参数文件时被转换为 parameters :: current_params%devel_code. 此块可以使用以下函数进行解析：

    • io :: io_code_present(code, key, block)

      检查某个特定参数是否 key 存在于块中 block如果未提供 block，则检查顶层 devel-code。

    • io :: io_code_block(code, block)

      返回整个区块 block 作为一个字符数组，允许你手动处理数据。大多数情况下适用于最终参数将是一块数据的情况。

    • io :: io_code_logical(code, key, block)

      解析给定参数 key 在块中 block 作为一个逻辑，根据列表导向的Fortran逻辑规则。

    • io :: io_code_integer(code, key, block)

      解析给定参数 key 在块中 block 作为一个整数，根据列表导向的Fortran整型规则。

    • io :: io_code_real(code, key, block)

      解析给定参数 key 在块中 block 作为一个实数，根据列表导向的Fortran实数规则。

    • io :: io_code_complex(code, key, block)

      解析给定参数 key 在块中 block 作为一个复数，根据列表导向的Fortran复数规则。

    • io :: io_code_string(code, key, block)

      解析给定参数 key 在块中 block 作为一个字符字符串。

    示例

    对于一个 devel_code 一个看起来像这样的块：

    %block devel_code
mod_param=17
XYZ: param=3 :ENDXYZ
%endblock devel_code

    处理开发版代码参数的常规步骤如下：

    module my_module
   ...
   ! Can read into module parameters if necessary
   integer :: module_param
   ...

   function use_devel_code()
      ! Ensure the devel_codes are available
      use parameters, only: current_params
      ! Ensure we can parse the devel-codes
      use io, only: io_code_present, io_code_integer
      ! Have the param available
      integer :: param


      ! Check that we're the master process for reading the strings
      if (on_root_node) then
         ! Check if the devel code has been set
         if (io_code_present(current_params%devel_code,'param','XYZ')) &
            ! Read and parse the parameter for use
            & param = io_code_integer(current_params%devel_code,'param','XYZ')

         !Since it's top-level we parse it without passing the block.
         if (io_code_present(current_params%devel_code,'mod_param')) &
            & module_param = io_code_integer(current_params%devel_code,'mod_param')

      endif

      ! Distribute the parameters to all nodes
      call comms_gcopy(param, 1)
      ...
