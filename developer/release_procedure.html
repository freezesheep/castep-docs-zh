    CASTEP 新版本发布流程

    中文译文 · 由本地英文文档翻译，已统一术语并进行重点抽查。 英文原文对照 · 翻译说明

    初始设置

    • 打开一个包含此检查清单的问题
    • 打开缺陷修复/发布分支
    • 挑选适当的修复补丁从 default
    • 更新版本号在 license.F90
    • 确保 BIOVIA 版本已打标签

    功能

    • 检查在中暴露的OTFG特性 cell
    • 检查CI
    • 为 ANVIL 上的发布分支创建专用管道
    • 在 Make 和 CMake 上运行完整的构建测试
    • 检查 make dist works -- 包括解包和仅从 dist 构建！

    • 检查是否 cmake -t dist 也编译并包含所有内容

    • 确保检查点前后兼容

    • 确保学术版与BIOVIA版本之间的兼容性

    • 检查 CASTEP 在 ARCHER2 上的构建和运行情况——同时使用 GNU 和 CMake

    • 检查一级节点机器上的GPU构建——GNU和CMake

    • 检查最旧和最新版本所支持的编译器，并相应地更新 README.install 文件。

    外部库

    • 检查已链接/包含的库版本是否有更新
    • 当前库：
      • dl_mg
      • 简单-DFTD3
      • d4
      • spglib
      • libxc
      • FoxXML

    外部工具

    • 检查了第三方工具和实用程序的已发货版本更新情况
    • 现有工具：
      • c2x
      • cif2cell
      • 优化了
      • BoltzTrap
      • SHengBTE
      • emc
      • atat
      • elastic_constants

    • 为最新的关键词更新 emacs_mode 键位

    • 检查 Python 组件和工具的版本要求是否仍然最新

    使用文档

    • 检查并更新 README.install 文档
    • 更新发布说明

    • 在福特文档中更新版本

    • 检查新参数（单元格和param关键字）

    • 新参数具有正确的帮助文本
    • 手册中记录了新的参数

    许可证

    • 更新校验和文件
    • 上传至 licences.stfc.ac.uk

    最终化

    • 标签 最终版本提交
    • 提前通知HPC提供商发布信息
    • 通知邮件列表关于版本发布
    • 更新 castep.org 以包含最新信息
    • 检查构建系统和文档在发布分支中的更新，并在必要时回退到默认分支
