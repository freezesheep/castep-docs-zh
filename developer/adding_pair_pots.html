    添加经验势函数

    中文译文 · 由本地英文文档翻译，已统一术语并进行重点抽查。 英文原文对照 · 翻译说明

    如果你能够访问源代码，那么很容易为经验势能添加一个新的公式。该模块的设计理念是，即使是没有Fortran专家知识的初学者程序员，也能轻松完成这一操作。

    进行此项计算的总结位于标题部分。 pair_pot.f90 源，更详细的描述如下。

    设置参数

    首先我们需要制作 pair_pot_type 了解你的势能。为了使用我们的势能，我们需要更新几个关键内容。首先，我们需要更新代码所查找的势能数量：

    BEFORE:
integer, parameter :: num_pot = 9

    AFTER:
integer, parameter :: num_pot = 10

    接下来我们需要告诉程序我们的势能项的关键词及其内部ID。这将是尚未被占用的最高数值。（注意：关键词必须长度为4个字符，并需用空格填充至该长度）：

    BEFORE:
integer :: lj=1,buck=2,coul=3,dz=4,pol=5,bb=6,bs=7,sw=8,mors=9
character(len=4), dimension(num_pot) :: name = &
    & ['LJ  ','BUCK','COUL','DZ  ','POL ','BB  ','BS  ','SW  ','MORS']

    AFTER:
integer :: lj=1,buck=2,coul=3,dz=4,pol=5,bb=6,bs=7,sw=8,mors=9,new=10
character(len=4), dimension(num_pot) :: name = &
    & ['LJ  ','BUCK','COUL','DZ  ','POL ','BB  ','BS  ','SW  ','MORS','NEW ']

    然后我们需要将我们的势能函数所使用的参数添加到 pair_pot_type这些参数的格式应为：

    • 变量名称应为你的势函数的关键字后加一个下划线，再接参数的名称或符号。

    • 它们应为类型 real(kind=dp).

    • 它们应该是可分配的，并且维度应等同于参与相互作用的粒子数量（即 2 体） \Rightarrow{} dimension(:,:)；三体 \Rightarrow{} dimension(:,:,:)).

    • 它们应该有一个注释，描述你势能的完整名称和形式。

    • 此外，还需要注意的是，Fortran是不区分大小写的，这意味着在变量名中不会区分大写和小写。

      !New example potential of the form b*exp(rij^-qi)*exp(rik^-qi) + (cos(rijk) - cos(s))
real(kind=dp), dimension(:), allocatable :: new_q
real(kind=dp), dimension(:,:), allocatable :: new_b
real(kind=dp), dimension(:,:,:), allocatable :: new_s

    我们现在应该进入 pair_pot_print 并将我们的势能添加到势能打印的1体和2体（以及可能的3体）部分。其形式为：

    • 一体

      if (pair_pot%pot_present(pair_pot%new)) then
   write(unit_out, 103) pre_str, 'r', pair_pot%cut_off(pair_pot%new, 1, 1), 'NEW'
   write(unit_out, 103) pre_str, 'q', pair_pot%new_q(1, 1), 'NEW'
end if

    • 两体

      if (pair_pot%pot_present(pair_pot%new)) then
   write(unit_out, 202) pre_str, 'r', pair_pot_print_combinations(pair_pot%cut_off(pair_pot%new, :, :), ispec, jspec), 'NEW'
   write(unit_out, 202) pre_str, 'b', pair_pot_print_combinations(pair_pot%new_b, ispec, jspec), 'NEW'
end if

    • 三体

      if (pair_pot%pot_present(pair_pot%new)) then
   write(unit_out, 301) pre_str, ispec_name, jspec_name, kspec_name
   write(unit_out, 103) pre_str, 'S', pair_pot%new_s(ispec, jspec, kspec), 'NEW'
end if

    并且，至此我们便完成了势能的设置 pair_pot_type，截断设置、势的启用等操作会根据势的关键词自动处理，不过某些特殊势可能需要更复杂的规则。

    分配与释放

    在 FORTRAN 中，确保我们的参数数组已分配非常重要。我们需要进入该子程序 pair_pot_allocate 并将其添加到该文件中。对于我们的示例势能函数，语法如下：

    if (pair_pot%pot_present(pair_pot%new)
   allocate(pair_pot%new_q(1:nspec),stat=ierr)
   if (ierr .ne. 0) call io_allocate_abort('new_q','pair_pot_allocate')
   allocate(pair_pot%new_b(1:nspec,1:nspec),stat=ierr)
   if (ierr .ne. 0) call io_allocate_abort('new_b','pair_pot_allocate')
   allocate(pair_pot%new_s(1:nspec,1:nspec,1:nspec),stat=ierr)
   if (ierr .ne. 0) call io_allocate_abort('new_s','pair_pot_allocate')
end if

    我们还需要在例行程序的最后对势场进行同样的清理工作。 pair_pot_deallocate:

    if (allocated(pair_pot%new_q)) then
   deallocate(pair_pot%new_q, stat=ierr)
   if (ierr.ne.0) call io_abort('Error deallocating new_q in pair_pot_deallocate')
end if
if (allocated(pair_pot%new_b)) then
   deallocate(pair_pot%new_b, stat=ierr)
   if (ierr.ne.0) call io_abort('Error deallocating new_b in pair_pot_deallocate')
end if
if (allocated(pair_pot%new_s)) then
   deallocate(pair_pot%new_s, stat=ierr)
   if (ierr.ne.0) call io_abort('Error deallocating new_s in pair_pot_deallocate')
end if

    初始化变量

    需要能够设置各个参数的值。为此，应添加一个初始化子程序。详细信息见可按需索取的示例文件。对于三体子程序，需要设置 pair_pot%three_body 标志在初始化时启用，并增加一个元素三元组循环。

    编写计算流程

    这是唯一需要由创建者决定如何设置的部分。该子程序应遵守以下内容：

    • 该子程序的名字应为 pair_pot_<new_potential>

    • 势能函数应包含一个标题，用于引用势能的来源及其形式。

    • 两体势能应遵循以下输入结构：

      subroutine pair_pot_new(pair_pot, rij, mod_rij_2, ispec, jspec[, spins], dfij, de)

      其中：

      • pair_pot 是类型 pair_pot_type 并包含你新势能函数的初始化参数。

      • rij 是类型 real(kind=dp) 维度为(3)，且是两个粒子之间的矢量。

      • mod_rij_2 是类型 real(kind=dp) 且是两个粒子之间的距离。

      • ispec 是类型 integer 且是原子 i 的物种。

      • jspec 是类型 integer 且是原子 j 的物种。

      • spins [可选] 的类型为 real(kind=dp) 维度为(4,2)，是(x, y, z, 大小)方向的自旋矢量对

      • dfij 是类型 real(kind=dp) 维度为(3)，且是两个粒子之间的矢量力。

      • de 是类型 real(kind=dp) 并且是两个粒子对总势能的贡献。

    • 要引用两体项，您应使用以下语法：

      pair_pot%new_b(ispec,jspec)

    • 三体势能应遵循以下输入结构：

      subroutine pair_pot_new(pair_pot, dr, mod_dr_2, rcjk, include_cjk, spec[, spins], dfij, de, stress)

      其中：

      • pair_pot 是类型 pair_pot_type 并包含你新势能函数的初始化参数。

      • dr 是类型 real(kind=dp) 维度为(3,3)，且是粒子三元组的矢量。

      • mod_dr_2 是类型 real(kind=dp) 为三维量，且是三粒子之间的距离。

      • rcjk 是类型 real(kind=dp) 为三维（3,3）维度，且表示单元格中粒子的绝对位置。

      • include_cjk 是类型 logical 三维的，并且是粒子间距离的大小是否小于截断距离。

      • spec 是类型 integer 维度为(3)，且是粒子的种类。

      • spins [可选] 的类型为 real(kind=dp) 维度为(4,3)，且是(x, y, z, 大小)的自旋矢量三元组

      • dfij 是类型 real(kind=dp) 为三维（3,3）维度，且是三粒子之间的作用力矢量。

      • de 是类型 real(kind=dp) 并且是相互作用对总势能的贡献。

      • stress 是类型 real(kind=dp) 维度为(6)，是粒子应力贡献的上三角部分。

    • 要引用三体项，应使用以下语法：

      pair_pot%new_s(spec(i_atom), spec(j_atom), spec(k_atom))

    自旋

    如果您的势能函数在力场中使用自旋，则这些参数会被传递给计算程序，作为一组四维矢量（两体相互作用为两个四维矢量，三体相互作用为三个四维矢量），其中四个参数分别对应三个方向和一个大小。

    添加贡献

    要真正告诉程序计算你所定义的势能对系统所做的贡献，我们需要将其添加到 pair_pot_contribution 子例程，两个体势能的语法如下：

    if (pot_include(pair_pot%new)) then
   call pair_pot_new(pair_pot, rij, mod_rij_2, species(1), species(2), dfij, de)
   e_cont = e_cont + de
   fij(:) = fij(:) + dfij(:)
end if

    三体势能目前更复杂，必须当前手动插入到循环中 pair_pot_calc，未来版本中将有简化此功能的目标。

    测试

    我们现在应该能够通过添加以下内容来激活您的势能。 NEW=T 进入 devel code 块后，可以像设置其他势能一样设置所有参数。

    为了验证你的势函数是否按预期工作，有几种内置方法可供开发者检查。

    1. 第一个是 FD_CHECK 开发代码，能够在势能评估的同时进行有限差分计算，并将输出结果保存到文件中 <seedname>.fd它还会在解析导数和有限差分导数不匹配时打印警告信息。你应该验证有限差分计算的力是否与解析导数一致。

    2. 第二个是 PRINT_POT 开发一个代码，用于在0到你的截断距离之间均匀分布的1000个点上评估你的势能，并将计算得到的力和能量输出到一系列名为的形式的文件中 <seedname>_<species_1>_<species_2>_<species_3>_<spin>.pot 这些只是具有如下形式的 3 列表格数据： Distance Energy Force 准备绘图了。

    3. 应为测试套件添加测试，以计算新势能函数在已知点处的值。
