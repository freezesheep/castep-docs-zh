    晶胞文件（.cell）

    中文译文 · 由本地英文文档翻译，已统一术语并进行重点抽查。 英文原文对照 · 翻译说明

    这是对CASTEP细胞文件选项的详细描述。见 基本单元文件页面 用于概览。本页包含最常用的单元格文件选项，但要获取完整集合，请使用 CASTEP 内置的帮助还有一个 单元格关键词简明表.

    cell 文件是 CASTEP 两个主要输入文件之一。它包含关于晶体晶格和原子位置的所有信息，以及诸如布里渊区采样（'k点'）、赝势、晶胞对称性、外部压力、原子或晶胞运动的约束，还有原子性质（如每种元素的质量）等附加信息。

    该文件本身是一种自由格式的关键字驱动文本文件，由关键字和信息块组成。这些内容可以按任意顺序给出，信息块由特殊符号指示。 %block 并且 %endblock 标记。大多数关键字和块是可选的，但 CASTEP 需要 两个块条目：一个块用于指定晶格，另一个块用于指定单元内的原子元素及其位置。

    至少必须指定晶格矢量和离子位置。对于未指定的其他参数，程序会采用合理的默认值。

    为以下定义的目的，所有由字母表示的变量均 R 被定义为实数，那些由 I 被定义为整数，那些由 C 是字符。

    说明

    数值可以指定为整数或浮点数，包括科学记数法，或者通过简单的算术表达式给出，涉及运算符 +,-,*,/，函数 cos, sin, tan （度）或 sqrt，例如 3.333e-1 -1/3,0.5*sqrt(2.0),cos(30).

    晶格矢量

    晶格矢量可以以笛卡尔坐标系的形式指定，或者以晶格矢量的大小及其相互之间的夹角来表示（a, b, c, \alpha, \beta, \gamma）。只有一个的 LATTICE_CART 并且 LATTICE_ABC 可能会出现在单元定义文件中。

    这些关键字的定义如下：

    %BLOCK LATTICE_CART
[units]
a_x  a_y  a_z
b_x  b_y  b_z
c_x  c_y  c_z
%ENDBLOCK LATTICE_CART

    这里 a_x 是第一个晶格矢量的x分量， \mathbf{a}, b_y 是第二个晶格矢量的y分量， \mathbf{b}，等等。

    [units] 指定晶格矢量的单位。若未提供，则默认单位为埃（Å）。

    %BLOCK LATTICE_ABC
[units]
a b c
alpha beta gamma
%ENDBLOCK LATTICE_ABC

    这里 a 晶格常数的值是多少？ \vert\mathbf{a}\vert, gamma 是晶胞角度的值吗？ \gamma （单位：度）等等。由于以这种方式指定晶格时其绝对取向是未确定的，CASTEP 会选取一个合适的取向，使布里渊晶格的对称轴与笛卡尔坐标系的 X、Y 和 Z 方向对齐。

    取向选择的详细描述

    立方晶系、正交晶系和四方晶系的常规单元胞具有 \mathbf{a}, \mathbf{b}, \mathbf{c} 沿 X、Y 和 Z 方向对齐。
    体心立方、面心立方、正交和四方原胞具有 \mathbf{a}, \mathbf{b}, \mathbf{c} 的 常规的 晶胞沿 X、Y 和 Z 方向对齐。
    三角形（H）和六角晶胞具有其独特的轴 \mathbf{a}, \mathbf{b} 或者 \mathbf{c} 分别沿 X、Y 或 Z 方向对齐。
    三斜（R）晶胞具有独特的轴沿Z方向对齐。
    单斜晶系： \mathbf{a} 位于X轴上， \mathbf{b} 位于Y轴上或在xy平面内如果 \gamma 是唯一的角度和 \mathbf{c} 沿着Z轴如果 \gamma 是唯一的角度。
    斜方晶系： \mathbf{a} 位于x轴上， \mathbf{b} 位于xy平面内且 \mathbf{c} 与……构成右手法则组 \mathbf{a} 并且 \mathbf{b}.

    注意

    用于计算的晶格参数的确切值可能与输入文件中指定的值有微小差异。 %BLOCK LATTICE_ABC

    %BLOCK LATTICE_ABC 是通过选择一组标准的晶格矢量方向，并将其按输入参数缩放来实现的。这会产生一个副作用，即消除晶格参数与理想布里渊区的微小偏差，实际上对晶格进行了“对称化”操作。这种情况通常是有利的！

    这不会调整离子位置，除非也设置了关键字 `SNAP_TO_SYMMETRY 为 TRUE。`

    [units] 指定晶格矢量模长所使用的单位。若未给出，则默认为Å。角度应以度为单位指定。

    离子位置

    离子位置可以指定为相对于晶胞的晶格矢量的分数坐标，或绝对坐标。仅一种方式 POSITIONS_FRAC 并且 POSITIONS_ABS 可能会出现在单元定义文件中。

    %BLOCK POSITIONS_FRAC
CCC_1  R_{1i}  R_{1j}  R_{1k}  [SPIN=s_1]
CCC_2  R_{2i}  R_{2j}  R_{2k}  [SPIN=s_2]
...
%ENDBLOCK END POSITIONS_FRAC

    一行中的第一个条目是物种（化学元素）的符号。 alternatively，也可以给出原子序数，此时 CASTEP 将根据原子序数查找对应的化学符号。一个符号最多可以有三个字符。前几个字母标识元素，由此可获得原子质量等默认值。

    下一行中 POSITIONS_FRAC 的前三个条目是表示离子在晶胞布拉菲格矢量分数位置的实数。

    如果可选标志 SPIN 位于一条线上，这设置了自旋极化（ N^\uparrow-N^\downarrow) 用于初始化自旋密度；对于非共线自旋计算，矢量自旋由三个数值指定。如果未提供此标志，则默认假设为非自旋极化状态。

    %BLOCK POSITIONS_ABS
[units]
CCC_1  R_{1i}  R_{1j}  R_{1k}  [SPIN=s_1]
CCC_2  R_{2i}  R_{2j}  R_{2k}  [SPIN=s_2]
...
%ENDBLOCK POSITIONS_ABS

    第一行的条目是离子物种的符号或原子序数，如同 POSITIONS_FRAC接下来三个条目是表示离子在直角坐标系中位置的实数。

    [units] 指定位置定义所使用的单位。若未提供，则默认为Å。

    可选标志 SPIN 如上所述定义 POSITIONS_FRAC.

    预定义结构

    或者，CASTEP 使用关键字编码一组预先定义的晶体结构。

    UNIT_CELL name
    其中 名称 可能例如 Si2, Si64, GaAs, Quartz, Graphene, MoS2, SrTiO3。要获取所有可能性的完整列表，请查询 CASTEP 内置的帮助功能 
    CASTEP --help UNIT_CELL
    此关键字与使用相互排斥。 %BLOCK LATTICE_CART/ABC 并且 %BLOCK POSITIONS_FRAC/ABS.

    布里渊区采样（k点）

    （注意：在以下部分中，带有前缀的关键词） KPOINT_ 并且 KPOINTS_ 是等价的。 KPOINT_ 是推荐的用法。

    在进行自洽计算以确定电子基态时，布里渊区的k点采样位置可以由指定一组k点或一个 Monkhorst-Pack 网格来定义，该网格可基于k点网格的维度或最小k点密度来描述。Monkhorst-Pack 网格的原点可以相对于布里渊区的原点偏移一个矢量。

    如果未指定k点，则默认将采用Monkhorst-Pack网格，最大间距为0.1Å。^{-1} 并且原点没有偏移。

    该 KPOINT_LIST, KPOINT_MP_GRID 并且 KPOINT_MP_SPACING 关键词是互斥的。 KPOINT_MP_OFFSET 可能与任一组合指定 KPOINT_MP_GRID 或者 KPOINT_MP_SPACING.

    %BLOCK KPOINT_LIST
\begin{array}{cccc}
R_{1i}  R_{1j}  R_{1k}  R_{1w}
R_{2i}  R_{2j}  R_{2k}  R_{2w}
...
%ENDBLOCK KPOINT_LIST

    一行中的前三个条目是k点相对于倒易空间晶格矢量的分数位置。一行中的最后一个条目是该k点相对于其他k点的权重。所有权重之和必须等于1。

    KPOINT_MP_GRID I_i I_j I_k

    这指定了在倒易空间晶格矢量方向上所需的Monkhorst-Pack网格的尺寸。生成的网格将为 I_i\times I_j\times I_k；任何由此生成（或提供的）对称性将在计算不可约楔时用于减少该数值。

    KPOINT_MP_SPACING R [units]

    单个条目是 Monkhorst-Pack 网格中 k 点之间的最大距离。网格的尺寸将被选择，使得k点之间的最大间距小于该值。

    [units] 指定k点间距的单位，尽管 请注意实际使用的单位是 2\pi 单位如果不存在，则默认为 ang-1，使得间距在 2\pi Å^{-1}.

    KPOINT_MP_OFFSET R_i R_j R_k

    这指定了Monkhorst-Pack网格相对于布里渊区原点的偏移量。三个条目是相对于倒易晶格矢量的分数坐标偏移量。

    用于执行谱计算的k点集可以以相同的方式指定，使用上述关键词的版本 SPECTRAL_ 前置。同样适用于互斥关键字的限制。

    对于非自洽谱计算，k点可以定义为沿倒易空间中的一条路径或一组k点列表。

    %BLOCK SPECTRAL_KPOINT_PATH
R_{1i} R_{1j} R_{1k}
R_{2i} R_{2j} R_{2k}
...
%ENDBLOCK SPECTRAL_KPOINT_PATH

    每行上的三个数字是顶点k点相对于倒易空间晶格矢量的分数位置。这些k点定义了一条连续的直线段序列，除非指定了关键字 BREAK 出现在k点序列中的单独一行。在这种情况下，连续路径将在紧接其前的k点处结束。 BREAK 关键词和k点下一个路径点的摘要。路径将为开放状态 除非列表中的第一个和最后一个点相同.

    如果该块为空 

    %BLOCK SPECTRAL_KPOINT_PATH
%ENDBLOCK SPECTRAL_KPOINT_PATH
    CASTEP 将根据布里渊格子选择一个合适的默认路径。

    空间群特定布里渊区顶点名称

    k 空间路径的顶点点也可以使用对应于特定空间群的特殊点标签名称来指定。例如，适用于面心立方（fcc）晶格的合适路径为

    %BLOCK SPECTRAL_KPOINT_PATH
G
X
U
Break
K
G
L
W
X
%ENDBLOCK SPECTRAL_KPOINT_PATH

    沿每条线段采样的点的最大间距由关键字定义 SPECTRAL_KPOINT_PATH_SPACING （默认值 0.1 \times 2\piÅ^{-1}）。如果需要，实际使用的间距可能小于此值，以确保该线段的长度是该线段上点间距的整数倍。

    或者，可以像指定主k点集一样，使用上述关键词的版本来指定进行能带结构计算的k点集，其中 SPECTRAL_ 附加。同样适用于互斥关键字的限制。在这种情况下，k点权重在 SPECTRAL_KPOINT_LIST 是可选的。如果省略，则假设每个k点的权重相等。

    对于声子谱计算，k点可以定义为倒易空间中一条路径上的点，或是一组k点列表，其定义方式与能带结构计算相同。相应的关键词与能带结构指定的关键词完全一致，初始 SPECTRAL_ 被任一替代 PHONON_ 或者 PHONON_FINE_, e.g. PHONON_KPOINT_LIST, PHONON_KPOINT_MP_GRID, PHONON_FINE_KPOINT_PATH, PHONON_FINE_KPOINT_PATH_SPACING.

    说明

    第一种形式 PHONON_KPOINT... 定义了进行动力矩阵直接计算的点，以及第二个， PHONON_FINE_KPOINT_ 指定用于生成动力矩阵的傅里叶插值所对应的集合。见（[声子]) 以获取更多详情。

    关于互斥关键字的相同限制也适用。

    关键字 block PHONON_GAMMA_DIRECTIONS 指定在计算LO/TO分裂的非解析项时，γ点将沿哪些方向逼近。此区块中的每一行将由一个3维向量组成，该向量表示在倒格矢基下的一个方向。如果未提供此关键字，则默认值为一个由下述方法确定的单个向量：

    1. 如果伽马点是 q_i = 0 并且存在一个后续的kpoint q_{i+1} 在列表中，则是 q_{i+1}.
    2. 否则如果伽马点是 q_i =0 并且存在一个前驱 kpoint q_{i-1} 在列表中则它是 q_{i-1}.
    3. 否则（即仅在Gamma点进行计算）晶格倒易空间中的a轴。

    为保持向后兼容性，以关键字开头的项 BS_ 并且 OPTICS_ 是 SPECTRAL_KPOINT_ 的同义词，同样那些以类似方式开始的项也是如此。

    晶胞对称性

    如果在单元格定义文件中未指定对称性，则默认情况下不应用任何对称性。

    SYMMETRY_GENERATE

    如果此关键字存在于单元格中，则将找到适用于该单元格结构的最高对称性群，并生成相应的对称操作。

    SYMMETRY_TOL R [units]

    该参数是判断对称性是否满足的容差值。如果某个离子与其对称位置的距离在该容差范围内，则认为对称性已满足。

    [units] 指定容差所使用的单位。若未提供，则默认单位为Å。

    或者，可以将对称操作直接提供在一段 SYMMETRY_OPS 块。晶胞的对称性表示为一系列在这些操作下晶胞保持不变的对称操作。每个操作表示为一个 3\times 3 数组。

    %BLOCK SYMMETRY_OPS
R_{11}   R_{21}   R_{31}
R_{12}   R_{22}   R_{32}
R_{13}   R_{23}   R_{33}
T_1      T_2      T_3

R_{11}   R_{21}   R_{31}
R_{12}   R_{22}   R_{32}
R_{13}   R_{23}   R_{33}
T_1      T_2      T_3
...
%ENDBLOCK SYMMETRY_OPS

    每行前三个字符包含3个条目，代表矩阵的一行 3\times3 数组。这些表示在笛卡尔XYZ坐标系中表达的对称操作的旋转矩阵。接下来一行中的三个条目包含与该旋转相关的平移，以晶胞矢量的分数形式表示。

    约束条件

    在松弛或分子动力学计算过程中，可能需要限制离子或晶胞的运动。

    离子运动的约束可以指定为一组线性约束。每个约束由一系列系数指定。 a_{ijk} 使得：$$ \sum_{k=1}^{\tt N_\mathrm{species}} \quad \sum_{j=1}^{\mathrm{N_\mathrm{ions}}(k)} \quad \sum_{i=1}^{3} a_{ijk} \verb#ionic_positions(i,j,k)# = \text{constant} $$ 其中 \mathrm{N_\mathrm{ions}}(k) 是物种中离子的数量 k.

    晶胞形状的变化也可通过关键字进行约束 CELL_CONSTRAINTS.

    约束离子质心保持固定的特殊情况由一个逻辑关键字支持 FIX_COM。此外，通过指定关键字也可以固定所有离子位置或晶胞参数 FIX_ALL_IONS 或者 FIX_ALL_CELL 要被 TRUE 相应地。

    如果在单元格定义文件中未指定离子或单元格约束，则默认情况下会固定质心。

    %BLOCK IONIC_CONSTRAINTS
I_1  CCC_{1s}   I_{1s}   I_{n1}   R_{1i}   R_{1j}   R_{1k}
I_2  CCC_{2s}   I_{2s}   I_{n2}   R_{2i}   R_{2j}   R_{2k}
...
%ENDBLOCK IONIC_CONSTRAINTS

    每行的第一个元素是一个整数，表示所指定的约束条件编号。第二个条目是该约束适用的离子物种的符号或原子序数。第三个元素是该物种内离子的编号。同一物种中离子的排序顺序即为它们在文件中出现的顺序。 POSITIONS_FRAC 或者 POSITIONS_ABS 块位于单元定义文件中。最后三个数字是实数，表示离子位置的笛卡尔坐标在约束求和中的系数。未明确指定的求和中所有系数将为零。

    在读取这些数据时，离子约束矩阵将被正交化。

    %BLOCK CELL_CONSTRAINTS
I_a      I_b      I_c
I_alpha  I_beta   I_gamma
%ENDBLOCK CELL_CONSTRAINTS

    前三个条目与三个晶格矢量的大小有关 a,b,c 以及角度部分的第二组三个条目 \alpha, \beta, \gamma.

    如果对应于大小或角度的条目值为零，则该量将保持不变。如果两个或三个条目包含相同的整数，相应的量将被约束为具有相同的值。如果在第1至第3个条目中出现一个大于0的正整数，则该整数不能出现在第4至第6个条目中，否则会意味着一个矢量长度和角度必须具有相同的值。

    物种特性

    物种的质量、表示离子的赝势以及用于群体分析的线性组合原子轨道（LCAO）基组的大小，可以在单元格定义文件中指定。

    %BLOCK SPECIES_MASS
[units]
CCC_1   I_1   R_1
CCC_2   I_2   R_2
...
%ENDBLOCK SPECIES_MASS

    [units] 指定质量所采用的单位。若未提供，则默认为原子质量单位。

    第一行中的第一个条目是物种的符号或原子序数。该值必须与材料学文档中物种的符号或原子序数相匹配。 POSITIONS_FRAC 或者 POSITIONS_ABS 块。每行的第二个条目是该物种的质量。并非所有物种都需要出现在其中。 SPECIES_MASS 块，如果未提供则假定该元素的默认质量。如果为某元素指定的初始字母符号不是周期表中的标准元素符号，则必须明确指定该元素的质量。

    %BLOCK SPECIES_POT
CCC_1   I_1   <filename>
CCC_2   I_2   <filename>
...
%ENDBLOCK SPECIES_POT

    第一行中的第一个条目是物种的符号或原子序数。该值必须与材料学文档中物种的符号或原子序数相匹配。 POSITIONS_FRAC 或者 POSITIONS_ABS 块。每行的第二个条目是包含表示离子物种的赝势定义的文件名。所指的文件可能是运行时生成赝势参数的定义文件，也可能是包含赝势数据的旧式赝势定义文件。

    并非所有物种都需要出现在 SPECIES_POT 块。如果未指定赝势，则将使用默认的赝势参数为指定元素生成赝势。如果物种标签的前几个字母不是周期表中的标准元素符号，则必须明确指定该物种的赝势。

    每种元素离子所带的电荷将由该离子对应的赝势决定。

    %BLOCK SPECIES_LCAO_STATES
CCC_1   I_1   I_{B1}
CCC_2   I_2   I_{B2}
...
%ENDBLOCK SPECIES_LCAO_STATES

    第一行中的第一个条目是物种的符号或原子序数。该值必须与材料学文档中物种的符号或原子序数相匹配。 POSITIONS_FRAC 或者 POSITIONS_ABS 块。第二个数字是进行布居分析时，物种在LCAO基组中使用的角动量通道数量。例如，对于碳原子（1s态为内层核心态），若要使用2s和2p态，则应设置为2。默认情况下，状态数量将被设定为完成价壳层至下一个稀有气体的适当数量。如果赝势中排除了浅层核心态，则该值为…… SPECIES_LCAO_STATES 该物种应包含在单元胞文件中，以确保使用有意义的基组。

    外部压力

    可以通过指定压力张量对晶胞施加外部压力。

    %BLOCK EXTERNAL_PRESSURE
[units]
R_{xx}   R_{xy}  R_{xz}
         R_{yy}  R_{yz}
                 R_{zz}
%ENDBLOCK EXTERNAL_PRESSURE

    [units] 指定压力定义所使用的单位。若未提供，则默认为GPa。

    条目 R_{xx} 是 xx- 压力的分量， R_{xy} 的 xy- 组件等等

    默认情况下不施加外部压力。

    离子速度

    初始离子速度可以在单元定义文件中以笛卡尔坐标指定。

    %BLOCK IONIC_VELOCITIES
[units]
CCC_1 V_{1x}  V_{1y}  V_{1z}
CCC_2 V_{2x}  V_{2y}  V_{2z}
...
%ENDBLOCK IONIC_VELOCITIES

    一行中的第一个条目是离子物种的化学符号（或原子序数）。如果指定了原子序数，则会查找正确的符号以对应原子物种。一个符号最多可以有三个字符。接下来的三个条目是表示离子在笛卡尔坐标系中速度的实数。

    [units] 指定位置定义所使用的单位。若未提供，则默认为 Å/ps。

    如果未指定此关键字且进行了分子动力学计算，则离子速度将被随机初始化以达到相应的温度。
