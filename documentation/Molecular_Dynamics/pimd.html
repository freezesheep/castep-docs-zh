    路径积分分子动力学（PIMD）

    中文译文 · 由本地英文文档翻译，已统一术语并进行重点抽查。 英文原文对照 · 翻译说明

    对于某些体系，当原子较轻且/或温度较低时，原子的零点运动（而非电子）可能变得显著。这需要超越玻恩-奥本海默近似的方法，该方法假设原子核可被视为经典质点。实现这一目标的一种方式是采用费曼路径积分方法来处理量子力学，并利用一个由“珠链和弹簧”构成的环形经典结构来表示量子粒子。这种方法与分子动力学（MD）结合，生成一组构型，因此该方法被称为路径积分分子动力学（PIMD）。通过轨迹平均，可以利用该方法计算量子期望值。因此，可以采用经典的分子动力学分析技术来获得量子值。

    关键词

    PIMD 是一种分子动力学（MD）方法，因此所有通常的 MD 关键字都适用。注意，目前仅支持 md_thermostat 是朗格万，但这适用于所有值的 md_barostat.

    要激活 PIMD，关键变量为：

    md_use_pathint : true
md_num_beads   : 2

    这会开启PIMD并设置为2个珠子。需要特别注意的是，珠子的数量是一个额外的收敛参数——当珠子数量趋于无穷大时，离散化的环会变成连续的路径积分。在实际应用中，对于轻原子（例如氢）且温度高于10K的情况，通常使用2到128个珠子；而在较低温度下，珠子的数量会显著增加。

    num_farms      : 2

    这是并行化PIMD计算的一个重要方法。通过任务农场机制，每个珠子可以分配给一个农场，因此农场的数量应为1（无农场）或 md_num_beads然后，PIMD 计算可以在并行模式下运行在 num_farms 处理器块，其中每个块中的处理器数量由通常的CASTEP+DFT并行化策略（k点、g矢量、能带等）决定。

    更高级的关键词是：

    md_pathint_init : point / Gaussian
md_pathint_staging : true

    这决定了给定原子的初始珠位置如何分配。'point' 将所有珠置于同一点，而 'Gaussian' 则使用高斯扩散函数，该函数对自由粒子在给定温度下的离域程度具有解析正确性。

    阶段模式变换是消除珠环动力学中自然谐波的关键方法，否则将显著降低时间步长，尤其是在低温条件下。

    输出文件

    进行PIMD计算时，存在 md_num_beads 生成的信息量增加了！因此，如果使用耕作方法，则仅将每个珠环的质心位置和速度等信息（对应于每个原子的经典位置）输出到 .castep 文件。每个虚时间值（标记每个原子珠体的循环索引）的坐标数据被写入单独的文件中。 farmXXX.castep 其中 XXX 是农场编号。如果未进行农场计算，则所有数据都会写入单一文件中。 .castep 对于文件中每个原子在每个真实时间步的每个环，使用回转半径张量分析其尺寸，并将 3 个 RGY 本征值及其对应本征矢也输出到主 .castep 文件中。

    此外，还有 beadXXX.md 生成的文件，每个对应一个虚时间值（珠子数量）。这些文件可用于不同的分子动力学分析技术，并且可以使用诸如 pimerge.pl 将每个真实时间值对应的全部珠子数据放入同一个文件中，这对于可视化珠子的动力学行为非常有用。

    使用 i-pi

    i-pi 是 3rd-i-party Python 包用于进行 PIMD 计算。该工具需要其他代码（如 CASTEP）来为给定构型生成力，然后可执行不同形式的 PIMD，包括中心 PIMD，而后者在 CASTEP 中并不原生支持。i-pi 通过互联网套接字与 CASTEP 进行通信。对这一功能的支持自 CASTEP v22 版本或更高版本起已内置。

    在 examples/castep 目录中有一个使用 CASTEP 运行 i-pi 的示例，同时还包含一个 'run_me' 脚本，该脚本会启动 i-pi 服务器，创建一组子目录（每个珠子一个子目录），然后启动独立的 CASTEP 客户端。如果以 PIMD 模式运行此程序，则不需要在其中设置 PIMD 变量。 .param 文件，而是位于一个 i-π 中 input.xml 文件。

    CASTEP .param 需要的文件关键字为：

    task       : socketdriver
socket_port: 31415
socket_host: localhost

    其中 task 告诉 CASTEP 与 i-pi 进行通信 socket_port （在这种情况下，它发送珠子坐标并返回能量和力）。 socket_host 可以是本地主机，或者是在远程服务器上运行时的互联网主机。

    更多信息，请参见 i-π 网站.
