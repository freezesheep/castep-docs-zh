    分子动力学基础

    中文译文 · 由本地英文文档翻译，已统一术语并进行重点抽查。 英文原文对照 · 翻译说明

    分子动力学计算的基础是时间步长的计算。在参数文件中，应以如下方式指定模拟所需的合适时间步长值。

    md_delta_t  = 2 fs

    指定时间步长时，可以使用任何有效的时间单位。要指定执行的时间步数，可使用例如

    md_num_iter = 500
    NB 此值为本次运行中需计算的步数。它并非一系列连续运行中累积的总步数。“MD时间”字段中的值在 <seed>.castep 文件记录累计时间。

    系综

    以下系综可以使用 CASTEP 进行模拟。

    NVE

    在此系综中，原子数量（N）、模拟单元的形状和体积（V）以及能量（E）保持不变。所守恒的能量是Born-Oppenheimer哈密顿量。

    E = \left<\Psi|\hat{H}_{e}|\Psi\right> + \frac{1}{2} \sum_{i=1}^{N}\sum_{j=1}^{N}\frac{Z_{i}Z_{j}} {|\mathbf{R}_{i}-\mathbf{R}_{j}|} +\sum_{i=1}^{N}\frac{P_{i}^{2}}{2M_{i}}

    以原子单位制表示。

    该系综是通过命令选定的

    md_ensemble  =  NVE

    在参数文件中。保守能量的实际值将是初始自洽密度泛函计算的结果加上初始离子速度的动能。

    这些离子速度以三种方式之一定义。

    • 通过在单元文件中显式定义离子速度，例如 

      %BLOCK IONIC_VELOCITIES
auv
H  xxxxx yyyyy zzzzz
H  xxxxx yyyyy zzzzz
O  xxxxx yyyyy zzzzz
%ENDBLOCK IONIC_VELOCITIES
      使用任何有效的速度单位（auv 是原子单位的速度），等等。

    • 根据参数文件中定义的初始温度，例如 

      md_temperature  =  293 K
      请注意，可以使用任何有效的温度单位来指定该参数。在这种情况下，初始速度会被随机赋值，使得总线性动量为零，并且瞬时温度与所指定的温度相匹配。由于动能和势能之间的均分原理，系统将达到平衡状态时，其温度会略有不同。

    • 通过从在目标温度下平衡的运行中延续获得。该运行可以是其他可用系综中的任意一个。这也将使用延续文件中的单元胞和离子位置。有关延续的详细信息，请参见“延续”部分。

    从续接文件中读取的速度将始终具有优先权。如果未使用续接文件，且两者 md_temperature 以及一个 IONIC_VELOCITIES 如果指定了块，则 md_temperature 关键词将被忽略。

    默认情况下，在NVE运行中不会计算压力。要覆盖此设置，请使用以下命令

    calculate_stress = true

    在参数文件中。

    NVT

    该系综是通过以下方式选定的

    md_ensemble  =  NVT

    系统将被演化到一个由以下定义的特定温度 md_temperature 上述使用的关键词。初始速度基于此温度设定，从一个文件中读取 IONIC_VELOCITIES 块位于单元文件中，或以上述方式从续接文件中读取。

    温度控制可以通过多种方法实现，所有这些方法都被证明能够正确地采样系综。其中一种是Tuckerman等人提出的确定性Nose-Hoover链方法。 1 并且通过选择与

    md_thermostat  =  nose-hoover

    在参数文件中。在NVT情况下，一个Nose-Hoover链被耦合到所有粒子的自由度上。也可以指定链的长度，例如

    md_nhc_length  =  5

    用于五个恒温器的链。

    在Nose-Hoover情况下，具有链状结构的 M 恒温器的作用 N_{f} 离子自由度的情况下，守恒量是伪哈密顿量

    \begin{equation} \mathcal{H} = \left<\Psi|\hat{H}_{e}|\Psi\right> + \frac{1}{2} \sum_{i=1}^{N}\sum_{j=1}^{N}\frac{Z_{i}Z_{j}} {|\mathbf{R}_{i}-\mathbf{R}_{j}|} +\sum_{i=1}^{N}\frac{P_{i}^{2}}{2M_{i}} + \sum_{i=1}^{M}\frac{p_{\xi_{i}}^{2}}{2Q_{i}} + N_{f}k_{B}T\xi_{1} + k_{B}T\sum_{i=2}^{M}\xi_{i} \end{equation}

    其中 Q_{i} 恒温器虚构质量是否从指定离子弛豫时间自动分配？ \xi_{i} 是恒温器的自由度。此内容会带有标签打印出来。 Hamilt Energy: 在每个时间步长中。一个没有链（即没有链）的Nose-Hoover恒温器。 M=1）已被知不是遍历的，因此应避免使用。

    第二种控制温度的方法是通过随机的朗之万恒温器。

    md_thermostat = langevin

    在这种情况下，打印出的哈密顿量能量是上述方程的值。该值不会被动力学过程守恒，但在平衡状态下不应出现长期漂移。

    最后，温度可通过霍沃-朗格vin恒温器进行控制。

    md_thermostat = hoover-langevin
    这是将一个直接作用于物理系统的确定性Nose-Hoover恒温器，与作用于Nose-Hoover变量的Langevin恒温器相结合，以确保系综的遍历性。

    对于每种方法，都应指定一个合适的恒温器过程松弛时间。这可以使用任何支持的时间单位，例如

    md_ion_t = 2.4 ps

    对于恒温器的弛豫时间为2.4皮秒。霍沃德-朗格vin恒温器对这一值的选择最不敏感。

    与NVE系综相同，压力默认不会被计算。这与NVE情况下的处理方式一样被覆盖。

    NPH

    在此系综中，模拟单元的大小和（如果需要）形状会变化以调节压力。未施加恒温器，因此焓（H）被守恒。

    该系综由以下内容指定：

    md_ensemble = NPH

    外部压力通过单元格定义文件中的任意有效压强单位设置。外部压力张量所需的对称性意味着只需指定上三角部分的分量，例如：

         %block external_pressure
     GPa
     0.5   0.0  0.0
           0.5  0.0
                0.5
     %endblock external_pressure

    指定一个各向同性的外部压力为0.5吉帕。在使用可变形状恒压器时，分子动力学也可以支持非各向同性的压力。

    速度被赋予使得初始温度等于 md_temperature，或从单元定义文件/续接文件中读取，如同在NVE/NVT情况下的处理方式一样。

    有两种恒压器方案可供选择。第一种限制晶胞的动力学仅限于各向同性的膨胀和收缩。该方法遵循Andersen的方法。2 以及霍夫曼34 经 Martyna 等人修正后5. 此项通过以下方式选定：

    md_barostat = andersen-hoover

    在这种情况下，打印出的哈密顿量能量是焓，加上与晶胞运动相关的动能。

    \begin{equation} \mathcal{H} = \left<\Psi|\hat{H}_{e}|\Psi\right> + \frac{1}{2} \sum_{i=1}^{N}\sum_{j=1}^{N}\frac{Z_{i}Z_{j}} {|\mathbf{R}_{i}-\mathbf{R}_{j}|} +\sum_{i=1}^{N}\frac{P_{i}^{2}}{2M_{i}} + \sum_{i=1}^{M}\frac{p_{\xi_{i}}^{2}}{2Q_{i}} + N_{f}k_{B}T\xi_{1} + k_{B}T\sum_{i=2}^{M}\xi_{i} \end{equation}

    另一种方案采用了 Parrinello–Rahman 方法。675

    参数文件中的以下行选择了此恒压器。

    md_barostat = parrinello-rahman

    单元的动力学包含九个自由度（其中六个是独立的），导致一个哈密顿能量为

    \begin{equation} \label{eq:ParRarNPH} H = \left<\Psi|\hat{H}_{e}|\Psi\right> + \frac{1}{2} \sum_{i=1}^{N}\sum_{j=1}^{N}\frac{Z_{i}Z_{j}} {|\mathbf{R}_{i}-\mathbf{R}_{j}|} +\sum_{i=1}^{N}\frac{P_{i}^{2}}{2M_{i}} + P_{ext}V + \mathrm{Tr}[{\mathbf{p}_{g}\mathbf{p}_{g}^{T}]}/2W \end{equation}

    对于两种恒压器，都应指定单元格运动的弛豫时间，并使用适当的单位时间，例如：

    md_cell_t = 20 ps

    此时用于计算一个虚拟质量 W 用于单元格动力学，并应远大于离子动力学的特征时间。

    NPH运动方程要求在每个分子动力学时间步中计算压力（应力）。每个时间步的值为 calculate_stress 因此在这种情况下是无关紧要的。

    可变晶胞意味着可变的倒易格矢，这对平面波基组有影响。当晶胞发生变化时，为达到指定截断能所需的平面波数量也会随之改变。

    因此，用户有两个选择。第一个是固定基组的大小。

    fixed_npw = true

    截断能现在是可变的，基组的质量也随之变化。因此，该选项仅应用于体积变化较小且相对于平面波数量已过度收敛的计算中。

    第二种选择是允许基组在每个时间步发生变化。

    fixed_npw = false
    这是默认值。通过在每个时间步从基组中添加或减去平面波，该设置保持截断能大致恒定。

    在两种情况下，通过在每个时间步对压力施加有限基组修正，可以减小 Pulay 应力的影响。当平面波数量固定时，忽略能量的常数修正项；而在平面波数量可变的情况下，能量修正不再为常数，需在每一步重新计算。

    NPT

    系综NPT通过以下命令指定：

    md_ensemble = NPT

    这可以使用 Nose-Hoover 或 Langevin 恒温器，以及 Andersen-Hoover 或 Parrinello-Rahman 恒压器。在所有情况下，动力学过程均可被证明正确地采样到等温等压系综。5

    所有与NPH和NVT系综相关的选项均适用。

    在兰格朗日动力学（NPT）情况下，输出的哈密顿能量与NPH系综中的能量相同，即上述方程所给出的能量。在诺斯-霍over NPT分子动力学情况下，哈密顿能量由下式给出：

    \begin{equation} \label{eq:HooverNPT} H = \left<\Psi|\hat{H}_{e}|\Psi\right> + \frac{1}{2} \sum_{i=1}^{N}\sum_{j=1}^{N}\frac{Z_{i}Z_{j}} {|\mathbf{R}_{i}-\mathbf{R}_{j}|} +\sum_{i=1}^{N}\frac{P_{i}^{2}}{2M_{i}} + P_{ext}V + p_{\epsilon}^{2}/2W + \sum_{i=1}^{M}\frac{p_{\xi_{i}}^{2}}{2Q_{i}} + N_{f}k_{B}T\xi_{1} + k_{B}T\sum_{i=2}^{M}\xi_{i} + \sum_{i=1}^{M}\frac{p_{\xi_{bi}}^{2}}{2Q_{bi}} + k_{B}T\sum_{i=1}^{M}\xi_{bi} \end{equation}

    在各向同性单元动力学的情况下，或

    \begin{equation} \label{eq:ParRarNPT} H = \left<\Psi|\hat{H}_{e}|\Psi\right> + \frac{1}{2} \sum_{i=1}^{N}\sum_{j=1}^{N}\frac{Z_{i}Z_{j}} {|\mathbf{R}_{i}-\mathbf{R}_{j}|} +\sum_{i=1}^{N}\frac{P_{i}^{2}}{2M_{i}} + P_{ext}V + \mathrm{Tr}[{\mathbf{p}_{g}\mathbf{p}_{g}^{T}]}/2W + \sum_{i=1}^{M}\frac{p_{\xi_{i}}^{2}}{2Q_{i}} + N_{f}k_{B}T\xi_{1} + k_{B}T\sum_{i=2}^{M}\xi_{i} + \sum_{i=1}^{M}\frac{p_{\xi_{bi}}^{2}}{2Q_{bi}} + 9k_{B}T\xi_{b1} + k_{B}T\sum_{i=2}^{M}\xi_{bi} \end{equation}

    在帕林诺-拉霍恩案例中。请注意，在每种情况下，晶胞的运动自由度都会耦合到另一条诺斯-霍沃链。
