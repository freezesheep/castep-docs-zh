    X射线结构因子

    中文译文 · 由本地英文文档翻译，已统一术语并进行重点抽查。 英文原文对照 · 翻译说明

    基本理论

    X射线结构因子（SF）强度可以通过涉及X射线的衍射实验来测量。 \gammaX射线或电子束。它与材料晶胞内的电子密度直接相关， n(\mathbf{r})，通过傅里叶变换1:

    F(\mathbf{H}) = \mathcal{F}[n(\mathbf{r})] = \int_\textrm{unit cell} n(\mathbf{r})\exp(i 2 \pi \mathbf{H} \cdot \mathbf{r}) \mathrm{d}\mathbf{r},

    其中 \mathbf{H} = h \mathbf{a}^* + k \mathbf{b}^* + l\mathbf{c}^* 是对应的散射矢量 (hkl) 平面，与 \mathbf{a}^*, \mathbf{b}^* 并且 \mathbf{c}^* 为传统晶胞的倒易晶格矢量。

    在平面波赝势密度泛函理论（DFT）代码中，计算结构因子（SF）是具有挑战性的，因为通常不会直接计算总“全电子”电子密度，且用于存储赝势价电子密度的快速傅里叶变换（FFT）网格空间分辨率不足，无法捕捉靠近原子核处总电子密度的快速振荡，因此需要高达数千 eV 的平面波能量截断。在 CASTEP 中，我们开发了一种高效且准确的方法来计算这些结构因子，而无需转向大尺寸的 FFT 网格或高能量截断的平面波基组。该实现的详细信息可参见论文（CITE PAPER WHEN PUBLISHED），但促成这一发展的关键观察是：电子密度可以被分解为以原子为中心的贡献部分，这些部分可以在独立的径向网格上进行处理。由此得到的结构因子具有如下形式2:

    F(\mathbf{H}) = \sum_{j} f_{j} (\mathbf{H}) \exp(i 2\pi \mathbf{H} \cdot \mathbf{r}_{j}),

    其中 f_j(\mathbf{H}) 是原子的有效散射因子 j 在晶胞内，定义为其实效原子密度的傅里叶变换 \rho_j(\mathbf{r}):

    f_j (\mathbf{H}) = \int \rho_j (\mathbf{r}) \exp(i 2 \pi \mathbf{H} \cdot \mathbf{r}) \mathrm{d}{\mathbf{r}}.

    引入热效应

    在实验中，热振动（即声子）可以改变（时间平均的）电子密度，从而影响表面态（SFs）。假设将每个原子分配的电子密度进行近似处理。 \rho_j(\mathbf{r}) 能完美地跟随其核运动，结构因子可以通过引入原子温度因子来包含这些热振动效应。 T(\mathbf{H}):

    F(\mathbf{H}) = \sum_j T_j(\mathbf{H}) f_j (\mathbf{H}) \exp(i 2 \pi \mathbf{H} \cdot \mathbf{r}_j).

    将原子的振动视为谐振子的运动，可以证明温度因子的形式为：

    T(\mathbf{H}) = \exp \left(-\frac{1}{4} \mathbf{H}^\mathbf{T} \mathbf{B} \mathbf{H} \right),

    其中 \mathbf{B}^{jk} = 8 \pi^2 \langle u^j u^k \rangle \langle u^j u^k \rangle 是原子的平均平方热振动位移。当振动为各向同性时，该方程简化为：

    T(\mathbf{H}) = \exp \left(-\frac{B |\mathbf{H}|^2}{4} \right),

    其中 B 被称为德拜-瓦尔因子。

    关键词

    目前，为了使 CASTEP（版本 21 及更高版本）能够计算 X 射线结构因子，所需的结构因子必须放置在之间 CALCULATE_XRD_SF: 并且 :ENDCALCULATE_XRD_SF 在……之内 devel_code 块的 seed.param 文件。例如，该 (111) 并且 (200) 并且 (220) SFs 可以通过在文件末尾附加以下代码来计算 seed.param 文件：

    %block devel_code
CALCULATE_XRD_SF:
1 1 1
2 0 0
2 2 0
:ENDCALCULATE_XRD_SF
%endblock devel_code

    或者，如果未列出结构因子，例如：

    %block devel_code
CALCULATE_XRD_SF:
:ENDCALCULATE_XRD_SF
%endblock devel_code
    然后，整个FFT网格上的SFs将被写入。

    热效应也可以通过在所需原子德拜-瓦勒（DW）因子之间插入来实现。 DW_FACTOR: 并且 :ENDDW_FACTOR 在……之内 devel_code 块的 seed.param 文件。对于各向同性的DW因子，可以像下面这样将DW因子的值写在相应的原子符号旁边：

    %block devel_code
DW_FACTOR:
Mg 0.305
O 0.340
:ENDDW_FACTOR

CALCULATE_XRD_SF:
1 1 1
2 0 0
2 2 0
:ENDCALCULATE_XRD_SF
%endblock devel_code

    或者，可以如下指定每种原子物种的整个各向异性位移张量：

    %block devel_code
DW_FACTOR:
Mg
0.305 0.000 0.000
0.000 0.305 0.000
0.000 0.000 0.305
O
0.340 0.000 0.000
0.000 0.340 0.000
0.000 0.000 0.340
:ENDDW_FACTOR

CALCULATE_XRD_SF:
1 1 1
2 0 0
2 2 0
:ENDCALCULATE_XRD_SF
%endblock devel_code

    说明

    结构因子计算是一种后处理计算，因此可以从先前密度泛函理论计算的成果中进行续算。 .check 文件使用该方法 CONTINUATION CASTEP 中的参数。
