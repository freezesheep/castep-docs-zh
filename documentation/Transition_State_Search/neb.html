    微扰弹性带法（NEB）

    中文译文 · 由本地英文文档翻译，已统一术语并进行重点抽查。 英文原文对照 · 翻译说明

    说明

    The NEB functionality in CASTEP was overhauled in version 22, with more efficient algorithms available. In order to use this new functionality, make sure you're **using CASTEP 22 or later**.

    背景与理论

    微扰弹性带法是一种常用于寻找两个结构之间最低能量路径的方法。你可以使用该方法来估算系统从一个结构过渡到另一个结构所需的能垒。

    在我们的NEB实现中，原子位置的更新规则由下式给出：

    x^{k+1}_{n} = x^{k}_n + \alpha^k [-\nabla^\perp V(x^{k}_n) + \mathbf{\eta}^{k}_n]

    其中 x^{k}_n 是镜像的位置吗？ n 在迭代中 k. \alpha^k 是步长，它可以是固定的，也可以以自适应方式选择。 \nabla^\perp V(x^{k}_n) 是总能量梯度，沿反应路径分量被投影去除后的部分，和 \mathbf{\eta}^{k}_n = \mathbf{\eta}((x^{k}_n)',(x^{k}_n)'') 是NEB弹簧力。

    由于投影步骤的影响，NEB力没有相应的能量泛函，因此无法进行线搜索，使得诸如(L)BFGS这样的拟牛顿搜索方法不再适用。标准方法要么采用仅基于梯度的简单方法，要么在代替线搜索时加入最大步长约束。这两种方法都可能表现出收敛速度慢的问题；一种更优的解决方案是使用自定义的时间步进算法来适当地选择步长。针对该问题的一个有前景的解决方案是ODE12r自适应方案。1，该方法结合了两种不同的步长选择准则：一种是基于最小化相邻步之间残差力的变化，这通常是自适应常微分方程（ODE）求解器中用于控制误差的方法；另一种是基于最小化残差本身。其核心思想是，在预渐近阶段应采用自适应ODE的步长选择方法，而在渐近阶段则适合采用最小化残差的方法。

    我们实现了三种NEB路径的优化方案，所采用的方法由以下内容控制。 TSSEARCH_NEB_METHOD 参数：(i) 巴兹利和博韦因提出的两点最速下降法2；(ii) 快速惯性弛豫引擎（FIRE3) 和 (iii) 的 ODE12R1 上述方案。在所有三种情况下，收敛性由现有 TSSEARCH_FORCE_TOL 参数。为了更好地符合用户直觉，该参数的默认值现在等于几何结构优化过程中使用的力容差。 GEOM_FORCE_TOL.

    我们还提供了三种替代算法来计算切线。 (x^{k}_n)' 以及曲率 (x^{k}_n)'' 在路径上的每一幅图像中，由以下内容控制 TSSEARCH_NEB_TANGENT_MODE 参数。三种方法基于二分法，以及FIRE的改进切线方案。3，以及 ODE12R 中使用的三次样条插值1后者被发现是最稳定的，因此被设为默认选项。

    关键词

    与其他 CASTEP 功能一样，您可以使用内置的帮助工具来查找与 NEB 相关的关键词信息。例如，您可以运行：

    castep -s tssearch

    相关的 .param 关键词汇总在下表中：

    参数 默认值 级别 说明
    TASK SINGLEPOINT 基础 设置为 TRANSITIONSTATESEARCH 进行过渡态计算。
    TSSEARCH_METHOD LSTQST 基础 用于定位过渡态的搜索方法。必须设置为 NEB 进行NEB计算。为保持向后兼容性而保留之前的默认设置。可修改项：仅重启（restart）。允许值： LSTQST, NEB 默认值： LSTQST
    TSSEARCH_FORCE_TOL 相同于 GEOM_FORCE_TOL 基础 接受 QST 搜索过程中最大离子力收敛的容差。可修改：续算和实时计算
    TSSEARCH_MAX_PATH_POINTS 20 中间状态 NEB搜索的最大路径点数。可修改项：续算和实时调整。允许值：(任意整数) > 0
    TSSEARCH_NEB_METHOD ODE12R1 中间状态 用于优化NEB形状的方法。可修改项：restart和on the fly。允许值： GRAD_BB2, FIRE3, ODE12R1
    TSSEARCH_NEB_TANGENT_MODE SPLINE 基础 用于计算NEB切线的方法。可修改项：restart和on the fly。允许值： NONE, BISECT, HIGH_E, SPLINE
    TSSEARCH_NEB_SPRING_CONSTANT 0.1 eV/Å² 基础 NEB搜索中图像之间的弹簧常数。可修改：续算和实时调整。允许值：(任意) > 0.0
    TSSEARCH_NEB_CLIMBING FALSE 基础 如果为 TRUE，则NEB搜索中的中心珠子会上升势能并 TSSEARCH_MAX_PATH_POINTS 必须为奇数（可增加 +1）。若为 FALSE，则NEB搜索中的中心珠会沿势能面下滑。可修改项：restart。允许值：TRUE 或 FALSE。默认值：FALSE
    TSSEARCH_NEB_MAX_ITER 20 中间状态 NEB搜索过程中最大步数。可修改项：续算和实时调整。允许值：(任意整数) > 0
    TSSEARCH_NEB_NORMED 错误如果 TSSEARCH_NEB_TANGENT_MODE = SPLINE，为真否则 专家 如果为 TRUE，则在NEB（能带路径）中沿切线方向施加的弹簧力将按珠子之间的位移进行归一化。如果为 FALSE，则弹簧力将沿NEB的切线方向投影，若位移与NEB切线方向正交，则可能导致力为零。可修改项：仅 restart。允许值：TRUE 或 FALSE

    至少你需要指定 TASK: TRANSITIONSTATESEARCH 并且 TSSEARCH_METHOD: NEB 在.param 文件中指定产物（最终）离子位置（例如使用 POSITIONS_ABS_PRODUCT 块）和一个过渡态猜测构型（例如使用） POSITIONS_ABS_INTERMEDIATE 块）在.cell文件中，除了正常的 POSITIONS_ABS 块。CASTEP 将从初始构型线性插值到中间构型，再从中间构型线性插值到最终构型，以开始 NEB 计算。

    然而，建议还应：

    • 改变所用图像的数量（TSSEARCH_MAX_PATH_POINTS),
    • 决定是否要使用爬升图像法（TSSEARCH_NEB_CLIMBING)，以及
    • 考虑应使用的相关力准则（TSSEARCH_FORCE_TOL).

    关于如何在CASTEP中使用NEB方法的实际指南，请参见 教程.
