    概述

    中文译文 · 由本地英文文档翻译，已统一术语并进行重点抽查。 英文原文对照 · 翻译说明

    计算的本质是逐步移动超胞中的离子和电子，直到原子所受的力以及相邻步骤间总能量的变化小于某个预定义的收敛容差。离子位置通过准牛顿方法进行优化。对于每一个离子位置构型，使用共轭梯度法对电子构型进行优化。因此，该计算流程为；

    1. 使用几何结构优化算法将离子移动到新位置
    2. 求该离子构型的电子能和力
    3. 比较总能量与前一构型，并检查力是否在容差范围内
    4. 如果结构未优化，从（1）开始并生成新的离子位置集合。此循环将持续进行，直到力的大小达到容差限值，此时能量应为局部最小值。

    在采用周期性边界条件（如 CASTEP 所使用）的情况下，除了（或代替）移动离子之外，还可以改变晶胞的大小和形状。此时，除了计算力之外还会计算应力，该应力被用来调整晶胞，直到应力降至给定容差范围内。

    最后，在考虑单元格变化时，也可以施加外部压力。因此，在这种情况下应最小化的自由能是焓，而不是能量。

    有限基组修正

    需要注意的是，当使用平面波基组（如CASTEP所采用的）时，改变单元格的大小和/或形状会产生一个重要副作用——它会改变用于电子态的基组。许多密度泛函理论（DFT）程序忽略了这一效应，这意味着如果晶格矢量的变化超过几个百分点，则最终结构将使用一个非自洽的基组进行评估，其截断能与预期值不同。在CASTEP中，这里存在两种选择：一是保持截断能不变（这导致每一步所使用的平面波数量及其意义发生变化）；二是保持平面波数量不变（这会导致截断能的变化以及每一步所使用平面波的意义发生变化）。默认情况下，CASTEP采用恒定截断能/可变平面波数量的方法，因为这是最符合物理实际的方案。而保持平面波数量不变的方法则意味着计算质量在不同步骤间会发生变化。

    改变晶格矢量对基组的影响也可以通过“有限基组修正”在一阶上进行校正。该修正可通过在计算开始时对截断能进行微小变化所引起的总能量变化来计算，并用作总能量和应力的校正项。这在变晶格体积的计算中尤为重要，此类修正默认已启用。

    高级设置

    在几何结构优化中，有多种不同的算法可供选择，可通过以下方式选定 geom_method 参数文件中的选项为：

    • LBFGS——BFGS算法的低内存版本——是默认选项
    • BFGS——广泛使用的拟牛顿最小化方法
    • TPSD - 两点最陡下降法
    • 去局域化——一种基于BFGS算法的最小化程序，使用去局域化的内部坐标
    • DMD - 最优阻尼分子动力学
    • FIRE - 快速惯性松弛引擎 - 一种改进的分子动力学方法

    NB 这些都是“局部优化”，即最终结构依赖于初始构型，并非全局最小值。对于希望寻找全局最小值的研究人员，已有采用遗传算法和AIRSS的相关项目。

    前 3 种方法可用于变胞或固定晶胞优化，后 3 种方法目前仅适用于固定晶胞。LBFGS/BFGS 通常速度最快。自 v19 起，LBFGS 支持新的预条件器，预期可进一步加速。TPSD 与 LBFGS/BFGS 不同，它没有内置历史记录，理论上因此较慢。不过，CASTEP 中高效的预条件器弥补了这一点。

    去局域化的最小化方法是唯一支持使用去局域化内部坐标（而非绝对或分数坐标）的方法，因此对于优化包含大量低能量软模式的大规模结构（如分子在盒子中的体系）而言，该方法最为合适。两种基于分子动力学的方法通常效率较低，但能很好地处理任意约束条件，并且在某些高度各向异性的体系（例如分子在表面体系等）中，其表现有时甚至优于其他方法。
