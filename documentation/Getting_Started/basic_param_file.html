    参数文件（.param）

    中文译文 · 由本地英文文档翻译，已统一术语并进行重点抽查。 英文原文对照 · 翻译说明

    这是参数文件的基本概述。详见 完整参数文件页面 详情请参见。

    参数文件是CASTEP的两个主要输入文件之一。它包含了您希望CASTEP执行的模拟类型的所有信息，以及CASTEP应如何执行这些模拟和额外的模拟与分析详情。

    该文件本身是一种自由格式的关键词驱动文本文件，主要由单行关键词组成，尽管其中包含少量信息块。这些内容可以按任意顺序给出，信息块由特殊标记指示。 %block 并且 %endblock 标记。所有关键字和区块都是可选的，但你几乎总是希望修改其中一些。

    任务

    此关键字控制CASTEP模拟任务的内容。默认值是

    task : energy
    这告诉 CASTEP 计算输入原子集合的基态电子能量和密度 cell 文件.

    截断能

    平面波截断能控制CASTEP为表示波函数而使用的基组的大小。截断能越高，所包含的平面波越多，波函数的表示也越精确，但这样会消耗更多的计算机RAM，并且计算时间也会更长。CASTEP计算始终是在所需的精度与模拟将使用的计算资源之间进行权衡。你需要的截断能还取决于以下因素： 赝势 你正在使用的在 单元格文件您可以从一些预设值中进行选择使用 basis_precision 关键词：

    basis_precision : coarse|medium|fine|precise
    即你可以选择设置 basis_precision 到 coarse, medium, fine 或者 precise.

    设置 coarse 并且 medium 通常仅适用于快速初步研究，而对于研究模拟，你通常希望将其设置为 fine 或更好。

    为了更精确地控制截断能，该 cut_off_energy 可使用关键词替代：

    cut_off_energy : 500 eV
    典型的截断能范围在300到1500 eV之间。

    交换关联泛函

    密度泛函理论在原则上是精确的，除了交换–关联（XC）泛函必须进行近似之外。存在许多不同的形式来近似这一部分，而在 CASTEP 中，您通过以下方式选择它： xc_functional 关键词，例如：

    xc_functional : pbe
    选择 Perdew、Burke 和 Ernzerhof 提出的 PBE 功能泛函。
