    用于声子及相关计算的单元格和参数文件关键字在此按字母顺序列出，并附有简要说明。

    CELL 文件关键字

    PHONON_FINE_KPOINT_LIST

    细网格上的声子波矢列表 （块）
    声子频率是使用DFPT在一组粗略的波矢上计算，并插值到更细的点列表上。

    PHONON_FINE_KPOINT_MP_GRID

    声子波矢的细粒MP网格 （整数向量）
    声子频率是使用DFPT在一组粗略的波矢上计算，并插值到更精细的波矢网格上。

    PHONON_FINE_KPOINT_MP_OFFSET

    细声子MP网格的Origin偏移量 （实向量）
    在使用DFPT计算声子时，细MP网格偏移量的插值位置。

    PHONON_FINE_KPOINT_MP_SPACING

    细粒度MP数据集中声子点的间距 （物理的）
    这指定了从较粗的声子网格中对声子进行插值时，单胞 Monkhorst-Pack 网格上点之间的最小间距。

    PHONON_FINE_KPOINT_PATH

    声子波矢路径的精细尺度示意图 （块）
    声子频率是使用DFPT在一组粗略的波矢上计算，并插值到更精细的路径上。

    PHONON_FINE_KPOINT_PATH_SPACING

    声子计算路径上点的精细间距 （物理的）
    k点沿路径的间距（由 PHONON_FINE_KPOINT_PATH) 处将从较粗的网格中插值声子

    PHONON_GAMMA_DIRECTIONS

    声子Γ点的LO/TO分裂 （块）
    这是沿哪些方向的列表 {\mathbf{q}}\rightarrow 0 将在声子计算中计算非解析的LO/TO项。 {\mathbf{q}}=0必须使用分数坐标。默认值：k点列表中gamma点之前的k点，或其后的一个k点，或(0.1, 0, 0)

    PHONON_KPOINTS_LIST

    别名 для PHONON_KPOINT_LIST （块）
    默认值：由确定 PHONON_KPOINT_LIST

    PHONON_KPOINTS_PATH

    别名 для PHONON_KPOINT_PATH （块）
    默认值：由确定 PHONON_KPOINT_PATH

    PHONON_KPOINTS_PATH_SPACING

    别名 для PHONON_KPOINT_PATH_SPACING （物理的）
    默认值：由确定 PHONON_KPOINT_PATH_SPACING

    PHONON_KPOINT_LIST

    声子 k 点列表 （块）
    一个用于计算声子频率和本征矢的离散k点列表。默认值：如果提供了替代k点，则使用SCF k点。 PHONON_KPOINT_* 未指定说明符。

    PHONON_KPOINT_MP_GRID

    声子波矢 Monkhorst-Pack 网格 （整数向量）
    由 Monkhorst-Pack 网格定义的声子波矢。若指定了对称性，则将使用该对称性生成波矢列表及其权重。

    PHONON_KPOINT_MP_OFFSET

    声子波矢 Monkhorst-Pack 网格偏移 （实向量）
    声子在分数坐标中的蒙克霍斯特-帕克集原点偏移，或关键字 INCLUDE_GAMMA. 默认值： INCLUDE_GAMMA

    PHONON_KPOINT_MP_SPACING

    声子波矢 Monkhorst-Pack 网格密度 （物理的）
    在声子计算中，Monkhorst-Pack 网格上波矢的密度。应指定单位为长度的倒数。默认值：0.1 埃^{-1}.

    PHONON_KPOINT_PATH

    声子色散 k 点路径 （块）
    在布里渊区中计算声子色散所经过的路径。该路径以分数坐标指定。默认值：None。

    PHONON_KPOINT_PATH_SPACING

    声子色散路径间距 （物理的）
    路径上k点之间的最大间距为 PHONON_KPOINT_PATH必须指定长度的倒数单位。默认值：0.1 Å^{-1}.

    PHONON_SUPERCELL_MATRIX

    用于有限差分声子计算的超胞矩阵 （块）
    用于力常数矩阵计算的超胞矩阵。超胞矩阵由一个3×3的整数矩阵指定，该矩阵给出了在有限差分声子计算中所使用的超胞。

    SUPERCELL_KPOINTS_LIST

    FD 声子超胞的 SCF k 点 （块）
    用于超胞FD声子计算中布里渊区积分的布里渊区k点列表（带有相应的权重）。k点权重之和必须为1。默认值：由以下内容生成 SUPERCELL_KPOINTS_MP_SPACING 以及晶体对称性。

    SUPERCELL_KPOINTS_MP_GRID

    FD 声子超胞计算的 SCF Monkhorst-Pack 网格 （整数向量）
    进行有限位移声子计算时，由 Monkhorst-Pack 网格定义的 k 点。若指定了对称性，则将使用对称性生成 k 点列表及其权重。默认值：从以下内容生成 SUPERCELL_KPOINTS_MP_SPACING.

    SUPERCELL_KPOINTS_MP_OFFSET

    FD 超胞声子计算中的 SCF Monkhorst-Pack 网格偏移量 （实向量）
    在执行有限位移声子计算时，Monkhorst-Pack 网格原点在分数坐标中的偏移量。默认值：(0, 0, 0)。

    SUPERCELL_KPOINTS_MP_SPACING

    FD 声子超胞计算的 SCF Monkhorst-Pack 网格密度 （物理的）
    用于超胞FD声子计算的Monkhorst-Pack网格的k点密度。应指定长度的倒数单位。默认值：0.1 Å^{-1}.

    PARAM 文件关键字

    NUM_BACKUP_ITER

    md/geom 迭代次数在备份之间 （整数）
    指定在几何优化或分子动力学运行中，每次数据备份之间的迭代次数，用于续算。允许值：（任意整数） > 0 默认值：5

    BACKUP_INTERVAL

    备份之间的秒数 （整数）
    指定几何优化/分子动力学/声子计算中所有数据备份的间隔时间（单位：秒），用于重启计算——若小于或等于零，则不进行定时备份。允许值：(任意) 默认值：0

    BORN_CHARGE_SUM_RULE

    强制执行鲍尔电荷和规则 （逻辑的）
    选择是否显式修正有效电荷张量，以强制有效电荷之和为零。

    CALCULATE_BORN_CHARGES

    计算Born有效电荷 （逻辑的）
    选择是否在声子或电场线性响应计算中计算本生有效电荷张量。允许值：TRUE 或 FALSE。默认值：TRUE

    CALCULATE_RAMAN

    计算拉曼强度 （逻辑的）
    选择是否在声子或电场线性响应计算中同时计算拉曼强度。允许值：TRUE 或 FALSE。默认值：FALSE

    EFIELD_CALC_ION_PERMITTIVITY

    计算零频介电常数 （逻辑的）
    指定是否基于离子对电场的响应来计算零频率介电常数。这需要在 EFIELD 线性响应计算之外，额外进行伽马点声子计算。允许值：TRUE 或 FALSE，默认值：TRUE

    EFIELD_CALCULATE_NONLINEAR

    计算非线性光学极化率 （字符串）
    选择在 TASK=EFIELD 计算中计算的非线性光学性质。允许值：NONE，CHI2。默认值：NONE

    EFIELD_CONVERGENCE_WIN

    EFIELD 中的收敛容差窗口 （整数）
    LR收敛准则必须满足 EFIELD_CONVERGENCE_WIN 接受前的迭代次数。允许值：（任意整数） \ge 2 默认值：2

    EFIELD_DFPT_METHOD

    E场 DFPT 求解器方法 （字符串）
    选择用于电场密度泛函微扰理论的求解器。允许的值：ALLBANDS（=VARIATIONAL）或DM（=GREEN），分别选择Gonze变分法或Baroni格林函数结合DM求解器。默认值：ALLBANDS

    EFIELD_ENERGY_TOL

    EFIELD 中 E(2) 收敛容差 （物理的）
    接受声子计算过程中场常数收敛的容差。max 和 min E(2) 值之间的差异过 EFIELD_CONVERGENCE_WIN 迭代次数必须小于这个值。注意：这是一个强度参数，其单位为体积。允许的取值：（任意） > 0.0 默认值： 10^{-5} A^3

    EFIELD_FREQ_SPACING

    介电常数计算中频率的间距 （物理的）
    频率计算中介电常数依赖频率部分的频率间隔。允许值：(任意) > 0.0 默认值：1.0 厘米^{-1}

    EFIELD_IGNORE_MOLEC_MODES

    忽略介电常数计算中的最低阶模式 （字符串）
    在计算介电常数和极化率的离子贡献时，忽略最低能量的（3,5,6）模式。允许值： CRYSTAL, MOLECULE, LINEAR_MOLECULE 默认值： CRYSTAL

    EFIELD_MAX_CG_STEPS

    EFIELD 中最大 CG 步数 （整数）
    EFIELD 计算中在执行 SD 重置前允许的最大共轭梯度步数。允许的值：（任意整数） \ge 0 默认值：0

    EFIELD_MAX_CYCLES

    EFIELD 中的最大循环数 （整数）
    EFIELD 计算中无论是否收敛，SCF 循环的最大数量。允许值：（任意整数） > 0 默认值：50

    EFIELD_OSCILLATOR_Q

    线形展宽的Q因子 （实数）
    振荡子Q因子，用于计算频率依赖介电常数时的线形展宽。允许值：(任意) > 0.0 默认值：50.0

    EFIELD_UNIT

    输出中电场的单位 （字符串）
    控制输出中所有电场使用的单位——支持多种不同的单位。默认值：eV/A/E

    ELEC_METHOD

    金属或有限温度绝缘体的处理 （字符串）
    金属或有限温度绝缘体的处理方法。是“的别名” METALS_METHOD允许的取值：NONE（=ALLBANDS），DM，EDFT，默认值：DM

    EXCITED_STATE_SCISSORS

    “剪刀”算子带隙修正 （物理的）
    有效为导带本征值添加一个偏移量，作为LDA/GGA对带隙低估的经验修正。允许值：（任意）默认值：0.0

    FIX_OCCUPANCY

    将系统视为绝缘体 （逻辑的）
    确定系统被视为绝缘体还是金属。允许值：TRUE 或 FALSE。默认值：FALSE

    GEOM_FORCE_TOL

    几何优化力收敛容差 （物理的）
    几何优化过程中接受最大离子力收敛的容差。允许值：(任意) > 0.0 默认值：0.05 eV/Å

    PHONON_CALCULATE_DOS

    态密度计算 （逻辑的）
    确定是否计算声子态密度。允许值：TRUE 或 FALSE。默认值：FALSE

    PHONON_DOS_SPACING

    态密度计算 （物理的）
    计算声子密度态所采用的分辨率。允许值：（任意） > 0.0 默认值：10.0 厘米^{-1}.

    PHONON_DOS_LIMIT

    态密度计算 （逻辑的）
    在声子密度态计算中包含的最大声子。允许值：(任意) > PHONON_DOS_SPACING 默认值：5000.0 cm^{-1}.

    PHONON_CALC_LO_TO_SPLITTING

    伽马点声子 LO/TO 修正 （逻辑的）
    选择是否计算来自长程电场效应的非解析贡献，这些效应导致LO/TO分裂。这需要通过电场线性响应和Born有效电荷来计算介电常数。允许值：TRUE 或 FALSE。默认值：TRUE

    PHONON_CONVERGENCE_WIN

    LR 中的收敛容差窗口 （整数）
    LR收敛准则必须满足 PHONON_CONVERGENCE_WIN 接受前的迭代次数。允许值：（任意整数） \ge 2 默认值：2

    PHONON_ENERGY_TOL

    LR 中 E(2) 收敛容差 （物理的）
    接受声子计算中力常数收敛的容差。max 和 min E(2) 值之间的差异过 PHONON_CONVERGENCE_WIN 迭代次数必须小于这个值。允许的取值：（任意） > 0.0 默认值： 10^{-5} eV/Å^2

    PHONON_FINE_METHOD

    细声子计算方法 （字符串）
    选择在细网格上进行声子计算所使用的计算方法。允许的值：NONE，SUPERCELL，INTERPOLATE。默认值：若TASK=THERMODYNAMICS则为SUPERCELL，否则为NONE

    PHONON_FINITE_DISP

    有限位移幅值 （物理的）
    用于有限位移声子计算的离子扰动幅度。允许值：(任意) > 0.0 默认值：0.01 a_0

    PHONON_FORCE_CONSTANT_CUTOFF

    力常数矩阵的截断值 （物理的）
    在使用超胞方法进行声子计算时，力常数矩阵的截断值。允许的取值：(任意) \ge 0.0 默认值：0.0

    PHONON_FINE_CUTOFF_METHOD

    选择用于从周期性超胞提取非周期性力常数矩阵的方法。 （字符串）
    随着 CUMULANT 方法中，将超胞的所有贡献项利用适当的权重因子相加，以避免图像贡献的重复计算。
    该 SPHERICAL 方法采用最小像约定，并使用一个由球形截断给出的截止条件 PHONON_FORCE_CONSTANT_CUTOFF.
    允许值： CUMULANT 并且 SPHERICAL. 默认值： CUMULANT.

    PHONON_FORCE_CONSTANT_CUT_SCALE

    球形力常数矩阵截断的缩放因子 （实数）
    所包含的力常数项范围延伸至距离威格纳-赛茨胞边界一半距离的 s 倍。该参数提供 s 的值。允许值：0.0 \le （任何） \ge 1.0 默认值：0.0

    PHONON_FORCE_CONSTANT_ELLIPSOID

    力常数矩阵的椭球大小 （实数）
    别名 для PHONON_FORCE_CONSTANT_CUT_SCALE （已弃用）。

    PHONON_MAX_CG_STEPS

    LR中CG步骤的最大数量 （整数）
    在声子计算中，执行SD重置前允许的最大共轭梯度步数。允许的值：（任意整数） \ge 0 默认值：0

    PHONON_MAX_CYCLES

    LR 中的最大循环数 （整数）
    无论是否收敛，声子计算中SCF循环的最大数量。允许值：（任意整数） \ge 0 或者如果 TASK=PHONON 等等 \ge PHONON_CONVERGENCE_WIN 默认值：50

    PHONON_METHOD

    声子计算方法 （字符串）
    选择用于声子计算的方法。允许的值：DFPT、LINEARRESPONSE、FINITEDISPLACEMENT。默认值：由 PHONON_FINE_METHOD

    PHONON_DFPT_METHOD

    声子 DFPT 求解器方法 （字符串）
    选择声子密度泛函微扰理论的求解器。允许的值：ALLBANDS（=VARIATIONAL）或DM（=GREEN），用于选择Gonze变分法或Baroni格林函数结合DM求解器。默认值：DM FIX_OCCUPANCY : FALSE，否则使用 ALLBANDS

    PHONON_PRECONDITIONER

    在LR中使用的方案 （字符串）
    LR中CG最小化器使用的预条件方案。允许值：RTPA、TPA、PS、NONE。默认值：TPA

    PHONON_SUM_RULE

    强制执行声子求和定则 （逻辑的）
    选择是否显式修正动力学矩阵以强制满足声子的声学q=0本征值规则，即在q=0时有3个模式频率为零。允许值：TRUE 或 FALSE。默认值：FALSE

    PHONON_SUM_RULE_METHOD

    选择用于强制满足声子求和定则的方法 （字符串）
    选择在强制满足声子求和规则时使用的处理方法。允许的取值：NONE：不应用求和规则修正。RECIPROCAL：在每个q点处，使用D(q=0)对倒易空间动力矩阵D(q)进行修正。REALSPACE：在实空间中修正力常数矩阵C(R)。REAL-RECIP：先在实空间修正C(R)，再在倒易空间修正D(q)。MOLECULAR：利用转动和平移求和规则修正D(0)。MOLECULAR-1D：针对线性分子，使用转动和平移求和规则修正D(0)。默认值：RECIPROCAL

    PHONON_USE_KPOINT_SYMMETRY

    在LR中使用减少或完整的k点集 （逻辑的）
    选择用于每个声子q矢量的k点集：T => 使用（简化的）对称性的不可约k点集，F => 使用完整的、完全对称的k点集。允许值：TRUE 或 FALSE。默认值：TRUE

    PHONON_WRITE_FORCE_CONSTANTS

    写出实空间力常数矩阵 （逻辑的）
    选择是否将从声子超胞或插值计算中输出实空间力常数矩阵（至） <seedname>.castep 文件）的情况中 PHONON_FINE_METHOD /= 无。允许值：TRUE 或 FALSE。默认值：FALSE

    PHONON_WRITE_DYNAMICAL

    写出倒易空间动力矩阵 （逻辑的）
    选择是否在声子计算中输出倒易空间的动力学矩阵（输出到） <seedname>.castep 文件）。/= NONE。允许值：TRUE 或 FALSE。默认值：FALSE

    THERMO_T_NPOINTS

    温度区间内的点数 （整数）
    温度区间内用于热力学计算的点数。允许值：（任意整数） \ge 1 默认值：2 如果 THERMO_T_STOP /= THERMO_T_START 或者为 1，否则

    THERMO_T_SPACING

    温度间隔 （物理的）
    热力学计算中温度值之间的间距。允许值：（任意） > (-ε) 默认值： THERMO_T_STOP - THERMO_T_START

    THERMO_T_START

    起始温度 （物理的）
    热力学计算所需的起始温度。允许值：（任意） > 0.0 默认值：298 K

    THERMO_T_STOP

    最终温度 （物理的）
    热力学计算所需的最终温度。允许值：（任意） \ge THERMO_T_START 默认值：298
