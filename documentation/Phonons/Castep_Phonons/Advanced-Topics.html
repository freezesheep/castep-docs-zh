    分子振动计算

    CASTEP 主要是一个用于固体状态的程序，具有周期性边界条件，因此并不一定是进行分子振动光谱计算的首选工具。然而，在某些情况下使用它于这种模式下可能是方便的（例如，当希望将分子晶体与孤立分子在完全相同的理论水平上进行比较时）。

    在一定限制条件下，可以使用 CASTEP 中的“分子置于大盒子”方法实现这一目标。其思路是通过构建一个大的超胞，将分子置于真空环境中。如果超胞足够大，使得分子的周期性镜像不再相互作用，则可以恢复出分子极限下的频率和本征矢。由于在大体积内零电荷密度仍需使用平面波基组表示，因此此类计算可能会变得昂贵，但进行仔细的超胞尺寸收敛测试仍然是必不可少的。

    一个位于自由空间中的分子同时具有旋转对称性和平移对称性，这导致其存在三个（对于线性分子则为两个）零频率的自由振荡模式。周期性的CASTEP计算不具此对称性，因此振荡模式的频率将具有非零值，要么是实数且为正，要么是虚数。若需要进行分子电场计算，则需使用参数

    efield_ignore_molec_modes

    可能通过关键字值指定 MOLECULE 或者 LINEAR_MOLECULE。这省略了红外极化率计算中的6（或5）个最低模式，假设它们是振转运动。

    如同晶体系统一样，通过最优取向来最大化对称性的利用是可取的。在这种情况下，还有一个额外的标准——模拟单元的矢量应尽可能与分子对称性相兼容。如果使用该方法，任何不兼容的对称操作都将不会被发现。 SYMMETRY_GENERATE 关键词。例如，四面体分子最好用立方晶胞建模，且三重对称轴沿立方体对角线方向取向。相比之下，苯这类六边形分子则更适合使用六方模拟单元，并将分子以相容的方式进行定向排列。

    该方法的一个局限性在于，CASTEP 只实现了晶格点群对称操作，而未包含所有分子点群。因此，并不能总是充分利用分子对称性，5重旋转轴和二十面体群无法被表示。在这种情况下，某些简并态将被打破且只能近似满足，分子点群的本征矢组合理论分析也将不准确。

    最后，有时希望计算离子而非中性分子的振动谱。这引入了不同程度严重性的若干复杂问题。首先，众所周知的是，半局域密度泛函理论（LDA 和 GGA）严重低估了阴离子的结合能，某些体系中分子态的描述可能存在显著错误。其次，在周期性单元中引入非零分子电荷时，必须添加一个补偿电荷以避免库仑能发散。CASTEP 隐式地添加了一个均匀的电荷分布，其在整个单元内的积分等于系统中离子和电子总电荷之和的负值。尽管该模型是有效的，但它会产生额外的静电项，这些项仅随距离衰减。 1/L^{3}因此，不可能完全收敛此类计算关于晶胞大小的参数。本文件不涉及描述用于恢复“无限”体积极限的技术方法。读者可参考文献（Leslie 和 Gillan 1985）以及大量引用该论文作为进一步阅读资料的文献。Parker 提供了一个成功方法的例子，该方法通过将分子阴离子的频率外推至无限晶胞极限来实现。 等 (Parker 等人，2006年).

    同位素替代计算

    实验光谱学中一种强大的技术是 同位素取代 其中样品通过将某元素的常见同位素替换为更重或更轻的同位素进行修饰。这种做法可以提供有价值的特定位置光谱信息，特别是当取代过程能够以特定位置方式进行时。力常数和动力矩阵与核质量无关，因此无论同位素如何替换，只需进行一次计算即可获得这些参数。 phonons 工具（章节） [声子工具]) 允许在无需重新计算动力学矩阵的情况下为不同的同位素取代重新计算频率。

    最简单的情况是完全取代。新的 .cell 文件应包含一个指定新质量的块， e.g.

     %block SPECIES_MASS
   H     2.014101778
 %endblock SPECIES_MASS

    运行程序 phonon 该程序将为一个完全氘代样品计算振动频率和本征矢。

    稍微复杂的情况是，当只希望取代若干个位点中的一个或少数几个时。在这种情况下，上述方法是不够的，因为它会改变所有含有该物种的位点。因此，必须使用 CASTEP 的亚物种标记功能。例如，包含甲烷分子的原始单元胞可能包含

    %block SPECIES_POT
C C_00.recpot
H H_04.recpot
%endblock SPECIES_POT

%block POSITIONS_ABS
C    0.0         0.0          0.0
H    0.0         0.0          1.09
H    0.9316592   0.0         -0.36333333
H   -0.4658296   0.8068405   -0.36333333
H   -0.4658296  -0.8068405   -0.36333333
%endblock POSITIONS_ABS

    延续单元用于输入到 phonons 应包含

    %block SPECIES_POT
C C_00.recpot
H H_04.recpot
H:D H_04.recpot
%endblock SPECIES_POT

%block POSITIONS_ABS
C    0.0         0.0          0.0
H:D  0.0         0.0          1.09
H    0.9316592   0.0         -0.36333333
H   -0.4658296   0.8068405   -0.36333333
H   -0.4658296  -0.8068405   -0.36333333
%endblock POSITIONS_ABS

%block SPECIES_MASS
   H:D     2.014101778
   H       1.007825032 
   C       12.0107 
%endblock SPECIES_MASS

    新的原子标签可能包含冒号后的任意字母数字扩展，最多8个字符。

    这定义了一个新的体系，其中甲烷分子中的一个氢原子被氘原子取代。请注意，这已经破坏了初始单元胞的对称性。 phonons 程序生成了一个具有三种不同原子类型的对称性降低的新体系，并从原始甲烷体系中复制动力矩阵数据至 .check 将文件传递到新体系中对应原子的位置。然后对动力矩阵进行对角化，应用所指定的任何后处理操作，并像往常一样写出频率和本征矢。

    这种直接方法未能考虑键长和几何构型中的同位素效应，因此仅是一种近似处理。由于键长的同位素效应又依赖于振动频率，在准谐振近似下，需要一种自洽方法，使键长和频率同时达到自洽状态。这还需要在每个阶段进行新的DFPT电子结构计算，超出了本工具的范围。

    约束晶格动力学

    有时希望计算材料某受限区域的振动频率。 从头计算 模型。考虑一个分子吸附在表面的情况。如果只需要分子振动的频率，则希望能够计算一组模式，只要这在技术上是可行的。虽然这在实际中并不现实（因为这需要事先知道完整计算的本征矢），但一种替代方法是施加对某些原子的约束。

    CASTEP 实现了一种称为 约束晶格动力学，也称为 部分赫塞矩阵 方法。被指定的原子被视为“冻结”，并将其动力矩阵中的相应项设为零。该模型实际上是一种将系统中被认为“无关”的区域内的原子质量设定为无穷大的模型。对于这些原子的扰动无需进行任何计算，从而可显著节省计算工作量。

    固定的原子在CASTEP中被指定 .cell 文件使用与几何操作相同的语法。该块

    %block IONIC_CONSTRAINTS
1 Si  1   1   1   1
2 Si  2   1   1   1
3 C   4   1   1   1
%endblock IONIC_CONSTRAINTS

    将硅原子编号1-2和碳原子编号4固定。这些原子在几何结构优化过程中不发生移动，其微扰在晶格动力学计算中也不被考虑。事实上，约束晶格动力学方法并未充分利用CASTEP线性约束模块的通用性（参见例如分子动力学教程中的相关内容）。 http://www.castep.org）但仅标识那些完全被约束不允许移动的原子。如上例所示，每个创建唯一编号约束的原子应有一条单独的记录。该记录在x、y、z位置均应包含“1”。

    除非在相当特殊的几何结构中，固定原子约束与大多数对称操作是不相容的，因此在受限晶格动力学计算中通常应关闭对称性。此外，它还与声学求和规则（第节）不相容。 [asr]) 作为约束原子会破坏哈密顿量的平移不变性。因此，如果存在约束，则会自动禁用声学求和规则修正。
