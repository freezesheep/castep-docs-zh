    介电性质

    中文译文 · 由本地英文文档翻译，已统一术语并进行重点抽查。 英文原文对照 · 翻译说明

    密度泛函微扰理论不仅限于原子位移微扰，还可用于计算绝缘体系对电场微扰的其他响应性质。1这些是介电常数

    \epsilon_{\alpha,\beta}^{\infty} = \delta_{\alpha,\beta} - \frac{4 \pi}{\Omega}\frac{\partial^2 E}{\partial \varepsilon_{\alpha} \partial \varepsilon_{\beta}} \;,

    “分子”极化率

    \alpha_{\alpha,\beta}^{\infty} = - \frac{1}{\Omega}\frac{\partial^2 E}{\partial \varepsilon_{\alpha} \partial \varepsilon_{\beta}} \;,

    以及Born有效电荷

    Z^{*}_{\alpha,\beta} = \Omega \frac{\partial P_{\beta}}{\partial u_{\kappa,\alpha}} = \frac{\partial F_{\kappa,\alpha}}{\partial \varepsilon_{\beta}} = \frac{\partial^2 E}{\partial u_{\kappa,\alpha}\partial \varepsilon_{\beta}}

    哪些在晶体的晶格动力学中起着重要作用，特别是调控红外区域的频率依赖介电响应（Gonze 和 Lee，1997).

    选择使用电场响应计算 task 关键词在……中 .param 文件。

    task : EFIELD

    计算光学频率介电常数张量以及低频（离子晶格）响应，该响应针对随时间变化的场，在声子模式和Born电荷的范围内。或者

    task : PHONON+EFIELD

    同时执行介电和声子任务。

    介电常数和极化率以及Born有效电荷的低频和近红外频率贡献被打印到 .castep 输出文件。图中展示了与之前相同的纤锌矿BN计算结果的提取内容。 [efield-out]. 一个额外的输出文件 seedname.efield 也已编写，并包含在整个范围内频率依赖的介电常数，其间距由参数决定。 efield_freq_spacing，以及由固定参数控制的洛伦兹展宽 Q, efield_oscillator_q.

    声子对介电极化率和介电常数的低频贡献，仅在所有模式频率均为实数且为正时才能被良好定义。当存在任一虚数频率或零频率模式时，低频介电常数和极化率张量将不被计算，并报告为“无穷大”。默认情况下，假设三个最低频率的模式为声学模式，并不包含在计算中。为了支持分子-超胞计算，参数 efield_ignore_molec_modes 可以设置为 molecule，其中排除了介电计算中的前6个低频模式。允许的取值是 CRYSTAL, MOLECULE 并且 LINEAR_MOLECULE 哪些忽略第3、第6和第5种模式分别。

    事实上，CASTEP 通常即使在没有电场的情况下也会执行电场响应计算。 task : PHONON 计算是因为需要介电张量和鲍林电荷来计算LO/TO分裂项。相反，一个纯 task : EFIELD 计算也执行一个 \Gamma用于计算介电常数和极化率中离子贡献的声子计算。因此，各项任务之间的唯一真正差异在于 PHONON, EFIELD 并且 PHONON+EFIELD 在于相同计算过程中输出文件中打印的内容。只有当其中一个属性通过某个参数明确关闭时才如此。

    phonon_calc_lo_to_splitting : FALSE
    efield_calc_ion_permittivity : FALSE

    是否曾进行过纯粹的声子或电场计算？

    众所周知，LDA 方法往往会高估介电常数——对于硅或锗而言，其误差超过10%。Levine 和 Allan，1989）。可以通过引入一个经验修正项来模拟缺失的自能，即应用所谓的“剪刀算符”，该算符由对导带所有态进行刚性上移构成。这一方法已被Gonze和Lee纳入DFPT电场响应计算中（Gonze 和 Lee，1997). 参数关键字

    excited_state_scissors 1.0 eV

    用于模拟导带态向上移动1 eV（以本例为例）的影响，并会包含对介电常数和Born电荷的影响（但不包括声子）。应从高精度计算或实验数据中确定该数值。

    非线性光学极化率

    除了使用任务计算的线性响应特性外 EFIELD 或者 phonon+efield 如果参数已知，则可以计算非线性介电极化率。

    efield_calculate_nonlinear : CHI2

    已设置。计算使用了DFPT的“2n+1定理”扩展。Baroni 等人，2001年; Miwa 2011) 用于计算静态响应， \chi^{(2)}结果在文中报告如下 .castep 以“d-矩阵”形式存储为简化张量形式的文件Boyd 2003）。见图 [非局域轨道].

    这默认是未激活的，因为它相比于基础的电场线性响应计算要昂贵得多。（即使对于具有更高对称性的晶体（例如立方对称），它也需要使用P1对称下的完整k点集来计算三组响应函数。）
