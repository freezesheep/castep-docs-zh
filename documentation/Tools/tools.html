    其他程序与工具

    中文译文 · 由本地英文文档翻译，已统一术语并进行重点抽查。 英文原文对照 · 翻译说明

    本页面列出了各种分析代码（其中一些随 CASTEP 分发包提供，其他则为第三方代码），这些程序可与 CASTEP 互操作。部分程序需要额外的接口代码/脚本，以将 CASTEP 输出作为其输入等。

    预处理工具

    • c2x （也随 CASTEP 分发包一同提供）可读取并转换一系列晶体结构文件格式，包括 .cif 这些功能与密度泛函理论（DFT）相关，并能执行结构操作。它可以旋转晶胞、生成超胞、添加真空空间、创建表面层和纳米管。
    • Cif2Cell 是用于从CIF（晶体学信息框架）文件生成各种电子结构代码的几何设置的工具。也支持超胞生成以及可视化工具的格式。
    • 见路径 是一个k路径查找器，提供与空间群对称性兼容的能带路径，并具备交互式3D可视化功能。

    收敛性测试

    • castepconv CASTEPconv（也随 CASTEP 分发包一同提供）可自动执行平面波截断能、k点密度和细网格尺度的收敛性测试。基于标准输入模板，它会生成相关文件、分析输出结果并生成汇总数据文件。独立版本随 CASTEP 源码一同提供。后续版本依赖于 ASE，并可在 github 上下载（https://github.com/CCP-NC/castepconv）并且还可以生成图表。

    通用后处理

    • castep输出结果 是一个Python包，用于读取和解析CASTEP的所有输出文件，并将其转换为标准格式。这是推荐的CASTEP输出解析接口。提供了一个简单的命令行工具以导出一个 .json 文件，但其主要用途是作为一个库，供未来的分析代码调用。这是为Python分析工具开发者推荐的接口。目前该程序可以读取并解析所有CASTEP文本格式文件，但不支持二进制文件。
    • castepxbin 是一组用于读取 CASTEP 二进制输出文件的程序集合 .check,.castep_bin, .orbitals 等等。
    • c2x （也随 CASTEP 分发包一同提供）可以读取 CASTEP 二进制输出文件 .check,.castep_bin,.orbitals 并提取单元格几何数据、电子密度、波函数，以供可视化和进一步分析。它可以通过三线性插值与傅里叶插值的组合对密度进行插值，对密度进行积分并计算其偶极矩，以及对能带进行倒易空间对称性分析。它可以生成与XCrysDen、VESTA、VMD和Jmol等程序兼容的输出格式，还可生成适用于gnuplot的1D数据格式。

    光谱建模工具

    • dispersion.pl 并且 dos.pl （CASTEP 分发包的一部分）是用于从 CASTEP .bands 文件生成能带结构和态密度图的工具。它们还支持生成声子色散和态密度图。Dispersion.pl 可对指定激光频率和温度下的粉末拉曼光谱进行简单的建模。
    • OptaDOS 是一种用于计算光学、内层电子激发谱以及全态密度、部分态密度和联合态密度（DOS）的代码。
    • SUMO 是一套用于电子能带结构和声子色散分析与绘图的工具。
    • PDielec 基于CASTEP（及其他）声子计算结果，计算包含光学谐振腔效应的模型粉末红外光谱。
    • 轨道到能带 （CASTEP 分发包的一部分）读取一个 CASTEP 文件 .orbitals 来自谱/能带结构计算的文件，分析能带交叉并生成一个 .bands 包含考虑交叉情况的重新排序本征值文件，用于生成能带图。
    • bs_sc2pc （CASTEP 分布包的一部分）是用于 CASTEP 的能带结构展开工具。它实现了 Popescu 和 Zunger 所描述的有效能带结构方法。 http://dx.doi.org/10.1103/PhysRevB.85.085201|10.1103/PhysRevB.85.085201，并作为 CASTEP 学术分发版的一部分提供。Peter Brommer 和 David Quigley（2014）“缺陷和不匹配超胞的自动有效能带结构。”《凝聚态物理杂志》26 485501。 http://dx.doi.org/10.1088/0953-8984/26/48/485501|10.1088/0953-8984/26/48/485501.
    • band_up 是另一个用于对缺陷超胞进行能带展开计算的程序。
    • easyunfold 是另一种能展开能带的工具，支持CASTEP。
    • 声子展开 是一个用于声子色散关系展开的程序。
    • mode_follow （CASTEP 分发包的一部分）读取一个 .phonon 输出文件并生成一系列 .cell 用于单点能计算的输入文件，用于沿模式计算能量轮廓，以便绘图和分析非谐性或双阱深度。
    • molpdos （CASTEP 分发包的一部分）在材料计算中计算态密度（DOS），以及将其投影到分子态上的态密度（DOS）。 ΔSCF 方法 计算。
    • Abins 是Mantid的一个插件，允许科学家将实验数据与理论弹性中子散射谱进行比较。AbINS利用由密度泛函理论（DFT）程序（如CASTEP）计算出的声子数据，生成粉末样品的中子散射谱，从而更方便地建立理论与实验之间的联系。
    • 悦耳的 是一个用于计算四维（4-D）中弹性的中子散射谱函数的库和前端Q,\omega) 空间与单晶时间飞行中子散射谱仪的数据进行比较。
    • OCLIMAX 是一款用于基于振动频率和极化矢量输入的非弹性中子散射模拟的免费程序。它既能对粉末样品也能对单晶样品进行模拟，输入的声子数据可来源于第一性原理或经验计算。
    • phonopy 是一个用于声子计算的开源软件包，支持谐波和准谐水平的计算。
    • phono3py 使用超胞方法计算声子-声子相互作用及相关性质。这些性质包括晶格热导率、联合态密度以及声子寿命。
    • 声子到json 一个小型 Python 工具用于转换 CASTEP .phonon 用于在中的文件 TSS 物理声子可视化工具.

    可视化

    • CrystalMaker 是一个用于设计和研究晶体与分子结构的可视化工具包。它还提供了对原子级和电子性质建模及动画的支持。
    • JMOL 是一个开源的基于浏览器的HTML5查看器以及独立的Java查看器，用于三维化学结构的显示，支持分子、晶体、材料和生物大分子。它能够读取CASTEP .cell, .castep, .den_fmt, .elf-fmt, .geom, .md, .phonon 以及更多内容，包括晶体结构、密度的可视化展示， 电子局域函数（ELF） 等等，以及优化或分子动力学轨迹的动画和声子振动。
    • MagresView 是用于可视化和处理计算固体态核磁共振参数的工具。
    • OVITO 是用于原子级和粒子模拟数据的科学可视化与分析软件。
    • VESTA 是一款用于结构模型、体数据（如电子/核密度）以及晶体形态的三维可视化程序。
    • XCrysDen 是一个用于显示等值面和轮廓的晶体与分子结构可视化程序，可将其叠加在晶体结构上，并支持交互式旋转和操作。（.c2x 可以将 CASTEP 输出转换为 .xsf 格式转换器及其他转换工具作为 CASTEP 分发包的一部分提供）
    • castep2fs 是用于从 CASTEP 输出文件生成可用于发表的费米面及相关数量的 CASTEP 工具。
    • castep2cube （CASTEP 分发包的一部分）读取 .check 或者 .castep_bin 输出文件，并将电子密度转换为高斯形式 .cube 格式，许多其他可视化工具均可读取。

    数据库、大数据与工作流

    • NOMAD 支持 CASTEP 及其用户。该服务包括上传、下载、共享、分配 DOI 等功能。数据存储期限至少为 10 年，这是多个资助机构的要求。NOMAD 仓库也是计算材料科学领域唯一被 NATURE Scientific Data 推荐的存储库。目前，该仓库包含超过 108 条目 - 请参见 档案 用于最新数据。
    • aiida-castep 接口到 AiiDA 工作流基础设施。
    • 萨普罗诺 是一个旨在帮助晶体学家搜索和分类特定材料新晶型的Python库。它提供了多种类和函数，用于处理大量候选结构、比较它们、排序和聚类它们。

    结构预测

    • CASTEP_GA （CASTEP 分发包的一部分）是一种基于改进型遗传算法（GA）的晶体结构预测工具，适用于周期性系统。它能够处理三维体材料、二维表面重构/界面以及一维纳米带边缘等结构。该工具维护一个初始晶态父代群体，通过变异和繁殖生成候选子代结构，随后将这些子代结构输入到CASTEP中进行局部结构优化。此外，还可以根据随机空间群生成随机结构。经过若干代演化后，可能会出现具有最低焓值的全局最优晶体结构。该功能已扩展至多目标遗传算法（MOGA），从而生成一组帕累托前沿最优结构，其中一条轴表示最小焓值，另一条轴为用户自定义的性质。分布中包含用于生成该性质值的示例脚本。最近的工作集中在CHGA（凸包遗传算法）方法上，该方法同时优化化学计量比，从而生成多维凸包。更详细的文档包含在“ReadMe”目录中。
    • AIRSS （从头算随机结构搜索）是一种非常简单、却强大且高度并行的结构预测方法。它生成具有合理密度和原子间距的随机合理结构，并将其松弛至附近的能量极小值。这些合理的随机结构在密度和原子间距方面都具备合理性，此外还可能包含晶体学、化学或先前实验/计算知识。除了这些明确的约束条件外，该方法的重点是广泛而均匀地对结构空间进行采样。它与CASTEP紧密集成，并已被用于多项里程碑式研究中，以发现材料的新相。
    • Calypso 《基于粒子群优化的晶体结构分析》是一种高效的结构预测代码。该方法仅需给定化合物的化学组成，即可预测在特定外部条件下稳定的或亚稳态结构，并可用于预测/确定晶体结构以及设计多功能材料。
    • USPEX （“通用结构预测：进化晶格学”）是Oganov实验室开发的一种用于晶体结构预测的方法。它能非常高效地处理分子晶体（包括具有柔性及极为复杂分子的晶体），并能够在仅给出化学元素名称的前提下，预测稳定的化学组成及其相应的晶体结构。除了完全非经验性的搜索之外，USPEX还能预测大量稳健的亚稳态结构，并可利用不同程度的先验知识进行多种类型的模拟。
    • XtalOPT 是一种免费且真正开源的进化算法，专为先验晶体结构预测而设计，作为对的扩展实现。 Avogadro 分子编辑器。

    分子动力学分析

    • geom2xyz.pl, geom2xsf, geom2dcd （CASTEP 分发包的一部分）是用于将 CASTEP 转换的过滤器 .geom 并且 .md 输出文件可转换为其他轨迹格式，并可用于与多种其他分析程序接口。
    • md_to_phonon （CASTEP 分发包的一部分）是一个简单的 Python 工具，用于读取 CASTEP 轨迹文件并进行各种基于声子的分析，包括质量加权速度自相关函数（VACF）随频率的变化（这与实验测得的 VDOS 相近）。该工具还可以从 VACF 中指定峰处提取特定的本征模式和本征矢，并将其写入单模式的 CASTEP 声子文件，以便用其他工具（如 JMol）进行可视化。
    • MDANSE 《用于中子散射实验的分子动力学分析》是一款用于分子动力学轨迹分析的Python应用程序。除了对结构和动力学进行一般性分析（如van Hove函数、振动态密度）外，它主要用于计算可直接与中子散射实验对比的性质，例如相干和非相干中间散射函数及其傅里叶变换、弹性非相干结构因子、静态相干结构因子或径向分布函数。
    • LiquidLib 是一个“用于分析经典和从头计算分子动力学模拟的液体及类液体物质，并应用于中子散射实验的综合性工具包”。
    • potfit 试图将一个模型力场拟合到所提供的数据集上。CASTEP 分发包中包含一个 Python 转换工具，用于读取 CASTEP 轨迹文件并生成可用于其他程序的原子构型文件。 potfit 代码。
    • MDTEP 是一个用于分析分子动力学轨迹并计算热力学性质（如比热容和速度自相关函数）的简单程序。

    机器学习势函数

    • QUIP 它是一组用于进行分子动力学模拟的软件工具。它实现了多种原子间势能和紧结合量子力学方法。详见 https://pubs.aip.org/aip/jcp/article/159/4/044803/2904492/Machine-learned-acceleration-for-molecular.

    输运

    • ShengBTE 是一个用于求解声子的玻尔兹曼输运方程的软件包。其主要目的是计算体单晶固体中晶格对热导率的贡献，但在假设扩散边界条件下，也可用于处理纳米线。
    • AlmaBTA 将目前用于均匀体材料的Sheng-BTE方法扩展至介观尺度，以完整描述从电子第一性原理层面、原子级层面，直至介观结构层面的热输运过程。
    • BoltzTraP 是一个用于计算半经典输运系数的程序。
    • BoltzTrap2 是平滑傅里叶插值算法在电子能带中的现代实现版本，该算法构成了原始且广泛使用的BoltzTraP程序的基础。BoltzTraP最典型的用途之一是在刚性能带模型下计算热电输运系数随温度和化学势的变化关系。然而，该程序还提供了许多其他功能，包括基于重构能带的三维费米面图示。
    • EMC （有效质量计算器）实现了利用有限差分法计算能带极值处的有效质量。该程序有两个版本：用FORTRAN编写和用Python编写。

    其他事项

    • ASE 是一套用于设置、操作、运行、可视化和分析原子模拟的工具及Python模块。该代码在GNU LGPL许可下免费提供。它可以与多种不同的电子结构计算程序进行接口连接。
    • 巴德尔 是一种对电荷密度网格进行Bader电荷分析的工具。在分子体系中，电荷密度通常会在原子之间达到最小值，这为将原子彼此分开提供了一个自然的位置。除了作为可视化分子中原子位置的一种直观方案外，Bader定义在电荷分析中也常常非常有用。例如，包含在Bader体积内的电荷是原子总电子电荷的良好近似值。
    • ATAT （合金理论自动化工具包）是阿克塞尔·范德瓦尔开发的一系列合金理论工具。
    • CASINO 是一个由剑桥大学物理系凝聚态理论组成员及其合作者在超过20年的时间里开发的用于执行量子蒙特卡洛（QMC）电子结构计算的计算机程序系统。它能够对由原子构成的真实体系的量子力学薛定谔方程求解出极其精确的解。一个接口 castep2casino 随 CASTEP 分发包提供。
    • Emacs 模式 （CASTEP 分发包的一部分）是用于 CASTEP 输入文件的 Emacs 主模式，具备基于数据类型的语法高亮和内置帮助功能。
    • i-PI 是一个通过 Unix 套接字驱动接口执行分子动力学和路径积分分子动力学的软件包。更多详情 其他地方 在此站点。
