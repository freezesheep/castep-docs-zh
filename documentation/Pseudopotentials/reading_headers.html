    在计算开始时，CASTEP 将生成所需的赝势。一份报告会被写入到文件的开头。 .castep 文件。本页面解释了该头部包含的信息。

    碳 - 超软

    ============================================================                
| Pseudopotential Report - Date of generation  8-07-2020   |                
------------------------------------------------------------                
| Element: C Ionic charge:  4.00 Level of theory: PBE      |                
| Atomic Solver: Koelling-Harmon                           |                
|                                                          |                
|               Reference Electronic Structure             |                
|         Orbital         Occupation         Energy        |                
|            2s              2.000           -0.505        |                
|            2p              2.000           -0.194        |                
|                                                          |                
|                 Pseudopotential Definition               |                
|        Beta     l      e      Rc     scheme   norm       |                
|          1      0   -0.505   1.395     qc      0         |                
|          2      0    0.250   1.395     qc      0         |                
|          3      1   -0.194   1.395     qc      0         |                
|          4      1    0.250   1.395     qc      0         |                
|         loc     2    0.000   1.395     pn      0         |                
|                                                          |                
| Augmentation charge Rinner = 0.983                       |                
| Partial core correction Rc = 0.983                       |                
------------------------------------------------------------                
| "2|1.4|10|12|13|20:21(qc=7)"                             |                
------------------------------------------------------------                
|      Author: Chris J. Pickard, Cambridge University      |                
============================================================
    所有量均以原子单位给出——能量单位为哈特里（1 Ha = 26.4 eV），长度单位为玻尔（1 bohr = 0.88 Ang）。

    • 元素：这只是该元素的符号
    • 离子电荷：核电荷与核心电子数之和（C Z=6，核心电子为1s²，离子电荷为+6−2=+4）
    • 理论水平：所使用的交换–关联势。
    • 原子求解器：Koelling-Harmon 是默认的原子求解器。

    参考电子结构。

    本节描述了计算中包含的价态。对于碳元素，这些是2s和2p态，其占据数和能量如下所示。

    赝势定义（高级）

    每个非局域投影算子（又称β投影算子）的定义如下。

    • Beta — 投影器的编号
    • l - 角动量量子数
    • e - 该轨道对应的能量
    • Rc - 轨道截断（匹配）半径
    • 方案 - 假设化方案（qc = qc 调优）
    • norm-1=模守恒 0-超软（模不守恒）

    这是一个带有每个角动量通道两个β投影函数的超软赝势。其中一个投影函数来自本征能级（即2s轨道的能量为-0.505 Ha）的轨道，而第二个投影函数对应于一个能量为0.25 Ha的非束缚轨道。

    最后一行给出了局部势的选择。在这种情况下，局部势是由一个l=2态构建而成，其截断半径与局部投影的截断半径相同。

    Augmentation charge Rinner这特指超软方案——它描述了增广电荷与全电子电荷相匹配的半径范围。

    Partial core correction由于交换关联能是电荷的非线性函数，如果我们分别计算价电子和核心电子的xc能量，则会引入误差。因此，我们在计算xc能量时将核心电荷一并考虑。核心电荷在网格上表示具有挑战性，因此采用赝势核心电荷。Rc 是该赝势核心电荷的截断半径。

    碳 - 正规守恒

    ============================================================                
| Pseudopotential Report - Date of generation  8-07-2020   |                
------------------------------------------------------------                
| Element: C Ionic charge:  4.00 Level of theory: PBE      |                
| Atomic Solver: Koelling-Harmon                           |                
|                                                          |                
|               Reference Electronic Structure             |                
|         Orbital         Occupation         Energy        |                
|            2s              2.000           -0.505        |                
|            2p              2.000           -0.194        |                
|                                                          |                
|                 Pseudopotential Definition               |                
|        Beta     l      e      Rc     scheme   norm       |                
|          1      0   -0.505   1.201     qc      1         |                
|         loc     1   -0.194   1.201     qc      1         |                
|                                                          |                
| No charge augmentation                                   |                
| Partial core correction Rc = 0.839                       |                
------------------------------------------------------------                
| "1|1.2|17|20|23|20N:21L(qc=8)"                           |                
------------------------------------------------------------                
|      Author: Chris J. Pickard, Cambridge University      |                
============================================================

    请注意， Reference Electronic Structure 该部分与上述超软赝势相同。这涉及全电子原子，且不受赝势细节的影响。

    从赝势的定义中我们可以看到，对于l=0（s）情况有一个β投影函数，而局部势被设定为l=1（p）。对于模守恒赝势而言，通常每个角动量通道只需要一个投影函数，并且其中一个占据通道可由局部势来表示。

    没有电荷增强（这仅适用于超软赝势），但使用了非线性核心修正。

    该赝势是通过包含自旋轨道相互作用的狄拉克方程求解器（FR=完全相对论）计算得到的。

    它是一个模守恒势。

    共有14个电子包含在价层中（6s², 7s², 6p⁶, 6d¹, 5f³）。由于自旋轨道分裂，具有不同j量子数的状态具有不同的能量。对于l>0的状态会分裂为 j=l+1/2 并且 j=l-1/2 （例如，6p 态分裂为 6p½ 和 6p3/2，5f 态分裂为 5f5/2 和 5f7/2）。
