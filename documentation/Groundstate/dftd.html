    长程色散修正

    中文译文 · 由本地英文文档翻译，已统一术语并进行重点抽查。 英文原文对照 · 翻译说明

    背景

    为何以及在什么情况下需要使用长程色散方法？

    范德华（vdW）相互作用在自然界中普遍存在，但标准的局域和半局域密度泛函近似（即LDA或GGAs）并未考虑这些相互作用。特别是，系统组分之间范德华相互作用的长程吸引力部分（伦敦色散相互作用）无法被捕捉。包含此类色散效应对于准确描述某些体系至关重要，尤其是那些不以离子键或共价键结合的体系，例如气体分子。

    当预期分子间相互作用起关键作用时（例如在分子晶体、堆叠的二维材料以及一般弱结合体系中），强烈推荐使用色散方法。

    修正方案类型

    存在多种散射方法家族。关于这些方法的一个良好总结可以在Grimme于2016年发表的综述中找到。 等.1 我们将在这里总结这些类别，并针对已在CASTEP中实现的部分，链接到相应的关键词。

    半经验/半经典处理方法

    此处色散能是按原子（通常为成对）计算，并加到基础泛函的密度泛函理论能量上。需要注意的是，通常会使用特定的阻尼参数（和函数）来将某一基础泛函（例如 PBE）与色散修正（例如 D3）相结合。这意味着，例如 PBE 泛函上的 D3 修正可能与 HSE 泛函上的 D等修正不同。

    方法包括：

    • Tkatchenko−Scheffler 方案（TS)
    • 基于TS的多体色散方案（MBD)
    • 格里姆梅的 D2 并且 D3 方法
    • 交换-偶极矩模型（XDM)

    基于非局域密度的处理方法（在CASTEP中未实现）

    此处构建了电子密度的非局域泛函。方法包括范德华泛函（例如 vdW-DF22 并且 vdW-DF-cx3) 以及 Vydrov 和 Van Voorhis 的泛函4.

    有效的一电子势（在CASTEP中未实现）

    最后，电子的多体相关运动在一定程度上可以通过使用有效的一体势来经验性地捕捉。这些例子包括：半局域泛函，例如明尼苏达泛函（例如）。 M065) 以及外部势场，如基于原子中心的色散校正势场（例如 van Santen 和 DiLabio，2015）6).

    通用建议

    每个应用都会有其自身的一组重要特征，因此无法确定哪种密度泛函近似最为合适。尽管如此，以下是一些针对不同类型材料的建议：

    • 分子晶体：D3-BJ/XDM/MBD 与 GGA 或杂化泛函结合（Dolgonos） 等., 20197).
    • 金属：为固态材料设计的vdW-DFs（范德华-密度泛函）（Klimeš） 等., 20118).
    • 分子与金属表面之间的相互作用：包含屏蔽的范德华-DFs或色散方法，例如TSSCS。
    • MOFs：包含散射修正（例如 TS、D3 等）的广义梯度近似（GGAs）
    • 层状范德华材料：超越成对方法，例如D3-BJ*或MBD。

    ^* 见下方注释了解如何在 CASTEP 的 D3 修正中包含三体项。

    再次，请自行进行测试，并查阅相关综述和基准论文。

    对于TS、MBD和XDM方法，如果您的晶胞较小（即晶格常数与范德华半径相当），可能会收到警告信息。这一问题已在学术版CASTEP v24.1中针对TS和MBD方法得到修复，在v25版本中针对XDM方法进行了修复。如果您使用的是较旧版本的CASTEP，则应尝试增大晶胞尺寸，直到色散修正收敛为止。

    并非所有 XC_FUNCTIONAL 所有方案均支持这些值——如有疑问，请使用PBE。XDM的主要‘XC_FUNCTIONAL’为B86BPBE。

    每个方案都为一组元素定义了默认参数（见 表格 下方）。对于其他元素，你需要使用以下方法定义自定义参数。 SEDC_CUSTOM_PARAMS 关键词在.cell 文件中。

    TSSURF 10 不确定是否在运行
    TSSCS 11 不确定是否在运行 最多到 Z=54，包含第一行镧系元素 解析的

    ^* DFPT：密度泛函微扰理论；FD：有限位移。

    以上所有方法均支持解析力。

    .cell 文件关键字

    在 .cell 文件你可以 可选地 为每种元素设置自定义参数：

    • C6 (eV Å)^6)：适用于 TS、MBD* 和 Grimme 方案。
    • R0 （埃）：适用于TS、MBD*和Grimme方案。
    • alpha (Å^3)：适用于 TS、MBD* 和 OBS 方案。
    • I (eV)：适用于OBS方案。
    • Rvdw （埃）：适用于OBS方案。

    你这样设置它们：

    %BLOCK SEDC_CUSTOM_PARAMS
      ! example values for test purposes only - don't use these... !
      He      C6:1.00      R0:2.00
      Ne      C6:10.00     R0:4.00
%ENDBLOCK SEDC_CUSTOM_PARAMS

    方法细节与自定义设置

    Tkatchenko−Scheffler 方案

    一种依赖密度的原子对散射修正方案。

    SEDC_SCHEME : TS

    限制条件：

    • 只能与以下交换关联泛函配合使用：PBE、PBE0、PBE1PBE、BLYP、B3LYP、AM0、RPB、PBESOL、PW91
    • 支持原子序数 Z≤54（Xe）以及第一列镧系元素。

    SEDC_SCHEME : TSSCS

    • TS 采用自洽筛选

    SEDC_SCHEME : TSSURF

    所有TS方案的自定义关键词

    .param 文件

    SEDC_SR_TS 类型：实数（浮点型） 等级：专家级别 描述：在TS半经验色散/范德华校正方案中，可自定义阻尼函数的SR值。 可修改：续算和实时调整 默认值由以下内容确定 XC_FUNCTIONAL.

    SEDC_D_TS 类型：实数（浮点型） 等级：专家级别 描述：在TS半经验色散/范德华校正方案中，可自定义阻尼函数的d值。 可修改：续算和实时调整 默认值由以下内容确定 XC_FUNCTIONAL.

    .细胞 文件

    SEDC_CUSTOM_PARAMS 类型：块；级别：基础；描述：用于半经验色散修正的自定义参数。用于计算范德华力。每种元素的默认值由所选的半经验修正方案确定。对于TS方法， C6 (eV Å)^6), R0 （埃）和 alpha (Å^3) 可以进行定制。

    多体色散

    在简单的二体色散方法所能涵盖的范围之外，MBD引入了：（1）多体能量（Axilrod-Teller及更高阶项）和（2）长程库仑响应（屏蔽效应），用于修正相互作用物种的极化率。

    SEDC_SCHEME : MBD

    • （别名： MBD*)

    请注意，两个别名MBD和MBD*均指代采用极化率自洽筛选（SCS）范围分离（rs）以及长程相关能计算的修订版MBD方法，即MBD@rs-SCS方法。

    限制条件：

    • 只能与以下交换关联泛函配合使用：PBE、PBE0、PBE1PBE、HSE03、HSE06、RSCAN
    • 支持原子序数 Z≤54（Xe）以及第一列镧系元素。
    • 请注意，在当前实现中，仅提供数值应力。
    MBD方案的自定义关键词

    .param 文件

    SEDC_SR_TS 类型：实数（浮点型） 等级：专家级别 描述：TS和MBD修正方案中阻尼函数的可定制SR值。可修改：续算和实时调整 默认值由以下内容确定 XC_FUNCTIONAL.

    SEDC_D_TS 类型：实数（浮点型） 等级：专家级别 描述：TS和MBD修正方案中阻尼函数的可定制d值。可修改：续算和实时调整 默认值由以下内容确定 XC_FUNCTIONAL.

    .细胞 文件

    SEDC_CUSTOM_PARAMS 类型：块级；层级：基础；描述：用于半经验色散修正的自定义参数。用于计算范德华力。每种元素的默认值由所选的半经验修正方案确定。对于MBD方法， C6 (eV Å)^6), R0 （埃）和 alpha (Å^3) 可以进行定制。

    Grimme D 修正项

    D2

    请注意，仅针对 PBE、BLYP、BP86、B3LYP、TPSS 函数时，默认的 D2 参数可用。您还可以使用以下关键字自定义校正参数：

    SEDC_SCHEME : G06

    说明

    这是 CASTEP 对 Grimme D2 修正的名称

    自定义关键词 G06

    .param 文件

    SEDC_S6_G06 类型：实数（浮点型） 等级：专家级别 描述：G06半经验色散/范德华校正方案中阻尼函数的可定制 S6 参数值。 可修改：续算和实时调整 默认值由 XC_FUNCTIONAL.

    SEDC_D_G06 类型：实数（浮点型） 等级：专家级别 描述：G06半经验色散/范德华校正方案中阻尼函数的可定制d值。 可修改：续算和实时调整 默认值由以下内容确定 XC_FUNCTIONAL.

    .细胞 文件

    SEDC_CUSTOM_PARAMS 类型：块级；级别：基础；描述：用于半经验色散修正的自定义参数。用于计算范德华力。每种元素的默认值由所选的半经验修正方案决定。对于Grimme的D2方法， C6 (eV Å)^6) 和 R0 (Å) 可以自定义。

    D3

    Grimme 的 DFT-D3 方法。采用 Becke-Johnson 抑制的 D3 方案（D3-BJ）通常更为准确。22 优于“零阻尼”方法（D3）。需要注意的是，大多数已发表的“D3”结果实际上指的是“D3-BJ”，而原始版本的D3现在已经很少使用。

    限制条件：

    • PBE、PBE0 和 HF 函数的默认 D3 参数可用。

    • 默认情况下， 未包含三体项。要包含它，请设置 d3_threebody: True 在……内 devel_code 块位于.param文件中。开启 IPRINT > 1 以获取关于D3修正项中包含内容的更多信息。

    • 在当前实现中，用户无法为该修正方案提供自定义参数。

    SEDC_SCHEME : D3

    SEDC_SCHEME : D3-BJ

    这是Grimme D3方案，带有Becke-Johnson阻尼。

    说明

    当运行带有 D3-BJ 计算时 IPRINT > 1，你可能会看到 Dispersion version: D4 在.castep输出文件中。令人困惑的是，这部分内容 不是 意味着使用了Grimme的D4方法，这只是该修正方案在CASTEP内部版本中的标签。

    编译标志：为了实现D3修正，CASTEP必须进行如下编译 GRIMMED3 := compile

    请注意，为了使 D3 修正项生效，CASTEP 必须在编译时包含以下标志： 

    # Grimme D3 library support. Options are none or compile
GRIMMED3 := compile
    在 Makefile

    对于 CASTEP 20，D3 库已包含在发行版中，设置上述标志应已足够。

    D4 一种普遍适用的、依赖原子电荷的伦敦色散修正，称为 DFT+D4。自 CASTEP 24.1 版本起，可通过设置实现。

    SEDC_SCHEME : D4

    请注意，D4 是通过使用外部方式提供的。 DFTD4 库。该库包含在 CASTEP 24.1 发布版本中，当你构建 CASTEP 时应默认进行编译。

    限制条件：

    • PBE、RPBE、PBESOL、BLYP、PW91 和 RSCAN 函数的默认 D4 参数可用。

    交换-偶极矩（XDM）方法

    一种统一的密度泛函处理动力学、非动力学和色散相关性的方法。

    限制条件：

    • 以下XC泛函的默认XDM参数可用：B86BPBE、PBE、BLYP、PBESOL、PW91、RPBE、WC、RSCAN

    SEDC_SCHEME : XDM

    对于本列表中未包含的功能化方法，你需要指定以下额外参数：

    自定义关键词

    .param 文件

    SEDC_A1_XDM 类型：实数（浮点型） 等级：专家级别 描述：XDM半经验色散/范德华校正方案中阻尼函数的可定制A1值。可修改方式：续算和实时调整 默认值：1.0

    SEDC_A2_XDM 类型：物理（浮点数）级别：专家描述：XDM半经验色散/范德华校正方案中阻尼函数的可定制A2值。可修改：续算和实时默认值由确定 XC_FUNCTIONAL.

    SEDC_SC_XDM 类型：实数（浮点）级别：专家描述：XDM半经验色散/范德华校正方案中阻尼函数的可定制SC值。可修改：续算和实时默认值由确定 XC_FUNCTIONAL.

    SEDC_C9_XDM 类型：逻辑值 层级：基础 描述：指定是否在XDM半经验色散/范德华校正方案中计算三体色散系数。 可修改：续算 和 实时计算 允许值： TRUE 或者 FALSE 默认值是 FALSE

    请注意，如果您希望尝试这些值，例如测试一种新的泛函，则需要进行更仔细的进一步验证。

    其他方案

    SEDC_SCHEME : OBS

    奥尔曼、贝克施泰特和施密特

    用于固体和分子结构密度泛函描述的半经验范德华校正

    自定义关键词

    .param 文件

    "SEDC_LAMBDA_OBS“类型：实数（浮点型）级别：专家描述：在OBS半经验色散/范德华校正方案中，可自定义阻尼函数的lambda值。可修改：续算和实时调整默认值由” XC_FUNCTIONAL.
