    ELF - 电子局域函数

    中文译文 · 由本地英文文档翻译，已统一术语并进行重点抽查。 英文原文对照 · 翻译说明

    基态电子密度，例如来自单点计算或分子动力学运行等，包含大量有用信息。它可以通过多种方式分析，电子局域函数（ELF）便是其中之一。这一概念最初由Becke和Edgecombe提出。1 用于分子的分析。该思想后来被Silvi和Savin扩展到了自旋系统，再进一步推广到固体状态系统。2后来发现，理论表达式并不严格正定，因此Jarvis和Carter增加了相关性修正。3，并且正是这种最终形式被实现于CASTEP中。

    ELF理论

    ELF 由下式给出

    \begin{equation} ELF = \frac{1}{1+\left( D/D0 \right)^2} \end{equation}

    Hartree–Fock 方法对应的表达式为：\begin{equation} D = \frac{\sum{\left| \nabla \psi \right|^2}}{2} -\frac{\left(\nabla n\right)^2}{8*n} \end{equation}

    与 \psi 为波函数和 n 电子数密度，以及

    \begin{equation} D0 = 0.3*\left(3*\pi^2\right)^{2/3}*n^{5/3} \end{equation}

    与 D0 是概率。因此ELF衡量由于Pauli排斥作用引起的额外动能，且这一定义是有界的 0<ELF<1过剩动能是费米子系统与玻色子系统在相同密度下的能量差。当电子成对出现且自旋相反，或处于孤立状态时，泡利排斥作用较小，过剩动能可忽略不计。因此，ELF（电子局域化函数）在系统更“玻色性”且局域化程度高的区域具有较大值，而理想氢电子气体（HEG）的ELF恰好为0.5。在非赝势计算中，ELF的绝对值具有实际意义；否则，它仅用于描述趋势。ELF可用于分类化学键和缺陷。

    CASTEP 的实现

    在 CASTEP 中，使用经修正的 DFT 形式：\begin{equation} D = -2*A*\sum{\psi^* \nabla^2\psi} + \frac{A}{2}\nabla^2 n - \frac{A}{4*n}\left(\nabla n\right)^2 \end{equation}

    并且 \psi 其中 psi 为 Kohn–Sham 波函数。第一项是非相互作用 Kohn–Sham 系统的动能，第二项是“关联修正”，第三项是相同密度下理想玻色气体的动能。另外：\begin{equation} A=\frac{\hbar^2}{2*m}. \end{equation}

    在存在自旋的情况下，有一个独立的 ELF_{\alpha} 并且 ELF_{\beta} 对于不同的自旋通道，每个表达式仅使用 n_{\alpha} 并且 \psi_{\alpha} 并且

    \begin{equation} D0_{\alpha} = 0.3*\left(6*\pi^2\right)^{2/3}*n_{\alpha}^{5/3}. \end{equation}

    CASTEP 使用赝势，因此 ELF 的绝对值无法转移到其他计算中，但仍然可以提供有关键合和缺陷等电子性质的有用见解。

    CASTEP 关键字

    默认行为是不计算ELF。可以通过添加以下内容来开启它 

    CALCULATE_ELF : TRUE
    到 .param 文件。ELF 将被写入一个二进制文件中，除非 
    WRITE_FORMATTED_ELF ; TRUE
    已启用。ELF文件（无论是格式化还是未格式化的）其内部布局与POT和DEN文件相同。通常使用如JMol等程序将其可视化为三维等值面。
