    弹性常数

    中文译文 · 由本地英文文档翻译，已统一术语并进行重点抽查。 英文原文对照 · 翻译说明

    安德鲁·沃克（在丹·威尔逊工作的基础上）提供了一些使用CASTEP计算弹性常数的Python脚本，可从以下位置获取 https://github.com/andreww/elastic-constants该工具包含两个部分：第一部分是 generate_strain.py，它接收一次成功完成的可变晶格几何结构优化的结果，并生成一组用于在 CASTEP 中运行的输入文件；第二部分是 elastics.py，它接收 CASTEP 的计算结果，并构建弹性常数矩阵、杨氏模量、泊松比以及体积模量和剪切模量。每个脚本的使用方法可通过使用 --help 选项获得。

    在本练习中我们将使用金红石-二氧化钛。以下是示例 .cell 并且 .param 要开始的文件。假设脚本 generate_strain.py 并且 elastics.py 已在你的 PATH 中，并且已安装 Python。

    #TiO2.cell
 %BLOCK lattice_cart
 4.594 0.000 0.000
 0.000 4.594 0.000
 0.000 0.000 2.959
 %ENDBLOCK lattice_cart

 %BLOCK positions_frac
 Ti  0.000  0.000  0.000
 Ti  0.500  0.500  0.500
 O   0.305  0.305  0.000
 O  -0.305 -0.305  0.000
 O   0.805  0.195  0.500
 O  -0.805 -0.195  0.500
 %ENDBLOCK positions_frac

 symmetry_generate

 kpoint_mp_grid 3 3 3

    #TiO2.param
 task             : geometryoptimisation
 cutoff_energy    : 700 eV
 xc_functional    : PBE
 max_scf_cycles   : 100
 calculate_stress : true
 opt_strategy     : speed
 num_dump_cycles  : 0

    • 任务1：执行可变单元几何结构优化，并确保在参数文件中包含 calculate_stress : true。测试动能截断值和k点网格，使应力收敛至默认的 geom_stress_tol 值以内。（提示：使用CASTEP内置的帮助工具查找默认值。）

    • 任务2：使用 generate_strain.py 生成一组根据适当应变模式变形的.cell文件的脚本。命令 generate_strain.py TiO2 应该已经足够了。你现在应该有十二组（在此情况下）输入文件——单独的.cell文件及其相应的 .param，符号上与原始内容相关联 TiO2.param 文件。请注意，所有新的.cell文件都已 FIX_ALL_CELL true 选项设置。

    • 任务3：在每组12个输入文件上运行CASTEP。请注意，晶胞的畸变可能会破坏晶体的对称性，因此会改变对称性降低后的样品中k点的数量。 -dryrun CASTEP 的选项可用于快速检查需要多少个 k 点。这在并行运行 CASTEP 时，有助于确定应使用多少个核心来运行计算。

    • 任务4：运行 elastics.py 获取弹性常数的脚本。命令 elastics.py TiO2 将在终端中打印结果。The --latex 选项生成结果的LaTeX格式摘要和 --graphics 选项会生成一个应力-应变拟合的图形表示，并保存为.png文件。

    • 任务5：研究结果及其误差如何随着较小的值变化。 elec_energy_tol 参数。此外，研究改变的效应。 --strain 选项以 generate_strain.py. 移动任何旧的 *cij*.castep 将文件移动到另一个目录 - 的 elastics.py 脚本只检查拼接数据中的第一组数据 .castep 文件。
